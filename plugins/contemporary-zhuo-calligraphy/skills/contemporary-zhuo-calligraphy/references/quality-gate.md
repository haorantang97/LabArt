# 生成质量门

评审对象是蒸馏后的跨文字风格语法，不是与某一张截图做像素或构图复刻。

## 硬失败

1. 指定文字有错、漏、重、繁简变化或额外文字。
2. 某个偏旁脱离母字，视觉上成为另一个独立字符。
3. 使用参考媒体、来源统计、逐字拼贴、字体渲染成品或原字复用。
4. 阅读方向或列顺序不符合请求。
5. 保留颜色引导、UI、印章、题款、水印或装饰物。
6. 清晰恢复为等宽列、等高行、共同横向基线或九宫格。

## 四维评分（每项 0–100）

- 字骨：是否出现多种结构角色与有因果的部件重分配，而非标准字骨加表面粗糙。
- 结体：重心、宽高比、疏密、错位是否显著不同且“拙而成立”。
- 笔性：钝压、涩拖、提锋、枯断与复得是否可信且不平均。
- 章法：列轴、推进、字距、侵入、退让与活纸是否形成关系场，而非排版网格。

任一项低于 75，只保存为失败样例。四项均不低于 75，只能称实验样图。

## 稳定性与高相似声明

- 用不同字数、不同偏旁构成且未参与规则编写的陌生文字测试。
- 不允许生成后挑字、贴字或不断抽样只展示幸运结果。
- 若要宣称 95%，必须预先固定至少三组陌生文本和评分表，由至少五名不知生成条件的评审打分，四维中位数均达到 95，并保存逐项记录。
- 未满足以上证据时，不宣称复刻作者、同一人写的或 95% 相似。
