# tephra 策略架构 v6（模块化）

原则：**一个模块负责一件事，模块之间不许互相偷偷改对方的参数。**
（历史教训：`--dissolve` 曾经偷偷把 `--mass` 从 0 改成 1，导致"只加一点溃散"实际换掉了整张图的画法。）

每个模块标注：**输入依据**（这个决定是从哪来的：实测 / 用户判断 / 物理）、**开关条件**、**与谁交互**。

---

## M0 · 输入判定（Intake）
在动任何渲染参数之前跑完。不通过就不要进 M1。

| 变量 | 含义 | 依据 |
| --- | --- | --- |
| （脚本 `dp_fitness.py`） | 中位亮度、可分离性 | 实测 4 张成功/失败样本 |

**判据**：中位亮度 < 0.20 直接过；否则要求可分离性 > 0.55。
**产出**：通过 / 需前处理 / 不适用。
**边界**：只判"能不能渲"，不产出任何渲染参数（除了 `--floor` 起点建议）。

## M0.5 · 前处理（Preprocess）
不改变构图与几何，只改明暗。四条互相独立，按需叠加：

| 规则 | 触发条件 | 手段 |
| --- | --- | --- |
| P1 反相 | 主体比背景暗 | `--invert` |
| P2 去梯度 | 存在大尺度亮度梯度（大气/景深/渐晕） | 减大尺度高斯背景 |
| P3 裁非画面物 | 水印/字幕/拼接缝 | **裁掉，不修补**（修补留下的直角缝会被忠实渲染） |
| P4 换轴 | 主体与背景亮度接近（差 < 0.05）但纹理差 1.5 倍以上 | 用局部对比度当门槛：`g = tone × (a + b·contrast)` |
| P5 重打光 | P1–P4 都救不回来，且需要"造出原图没有的层次" | img2img，denoise 0.25–0.35，三关验收（**几何锁死**） |
| P6 边缘围合填充 | 纹理门删掉了主体里**光滑**的部分（肢体、器物平面） | `gate += k·fill·clip(1−2.2·lc)`，填充**只在低纹理处开门**，否则主体被压成剪影 |
| **P7 局部重打光** | **见下：分界在源头就不存在** | 只改明暗，**几何仍然锁死**。三种手段，优先级从低到高 |

### P7 · 局部重打光（数字绿口红）

黑白电视时期演员涂绿口红——红色在正色胶片上拍成近黑，绿色才出正确灰阶。
关键：**演员的嘴唇还是那个形状那个位置，改的只是颜料对介质的响应。几何一个像素没动。**

**触发判据（量化）**：
某个"必须可辨认"的结构，与相邻区域的亮度差 **< 0.25 × 该区域自身局部标准差**
→ 这条分界在本语言里不可达，任何 floor / 曲线 / 纹理轴都救不回来。停止调参。

> 实例：木马抬起的前腿 vs 紧邻躯干，源图差 0.022 = 腿自身标准差的 **0.16 倍**；
> 进渲染器后差 0.011 ≈ 密度差 1.3%，84% 留黑下不可见。
> 但蹄 vs 天空差 0.365 —— **外轮廓够，缺的只是内部明暗分离**。
> 这是**打光问题不是造型问题**，所以不需要动几何。

**三种手段（优先用低档的）**：

| 档 | 手段 | 动了什么 | 保真关 |
| --- | --- | --- | --- |
| **7a** | **计算式加光减光**：从源图自身几何合成轮廓光/暗缝 | 只有明暗，确定性，无幻觉 | 全局保真不变 |
| **7b** | **局部 img2img 重打光**：只在框住的小区域内改光 | 只有明暗，几何锁死 | 编辑区外仍要 > 0.55 |
| 7c | 改几何（加不存在的边、分开粘连部件） | 造型 | 放弃保真 |

**7c 是最后手段，而且这次的木马用不着**——先试 7a，不够再 7b。
凡是"外轮廓已经够、只缺内部分离"的情况，一律不该走 7c。

**边界**：
- 只对**必须可辨认**的部件用（脸、手、蹄、桅杆、字）。装饰细节丢了就丢。
- 改动必须**局部**；其余仍走 P5 的几何锁死。
- 用了 7c 才需要声明"这是再创作"；7a/7b 仍是转译。

## M1 · 形体（Form）——画面里"是什么"
互斥的三种画法，一张图只能选一种作为底：

| 画法 | 参数 | 何时用 |
| --- | --- | --- |
| **纯粒子（正典）** | `--mass 0` | 默认。所有连续光影塑形的图 |
| 网点实体层 | `--mass 1`, `--plan` | 仅当输入是平实大色块。**v4 遗留，默认关闭** |
| 锚定物 | `--anchor` | 局部。画面里某个具体的物需要保真保留 |

### M1.a 锚定物（Anchor）
`--anchor X,Y,RX,RY[,S][,#色][,块][,曝光][,黑点分位][,彩度]`

- **不做主体分割**。逐 RGB 通道对源图抖动：暗的自己不印、彩的自己出色。
- 黑点分位从椭圆区内自取（区内多数面积是背景 → 背景自动归零）。
- 彩度提升必须按已有彩度开门，否则中性色会被放大成假色。
- `--anchor-src` 从另一张图取像素——**仅限同光照的另一版分级**，不能拿日景补夜景。

**边界**：anchor 是保真复制 + 降分辨率，不是"从灰度里长出实体"。两者不要混。

## M2 · 笔触质感（Mark）——每一笔"长什么样"
只描述单笔的形态，不涉及它往哪走。

| 变量 | 作用 | 当前值 | 依据 |
| --- | --- | --- | --- |
| `--stroke` | 最长笔长 | 20–22 | 用户实测 |
| `--length-mix` | 长短混搭的偏斜 | 3 | 用户："同一段线条由多个不同长度堆砌" |
| `--aniso-len` | 各向异性区才允许长笔 | 1.5 | |
| `--fray` | 子段错位（"脏"） | 1.4 | 用户："每个线条里都有错位感" |
| `--gap` | 子段断口 | 0.22 | |
| `--jitter` / `--curve` | 单笔的歪 / 弯 | 0.02 / 0.03–0.05 | curve 高了长笔卷成逗号 |
| `--density` / `--sparsity` | 落笔密度 / 留黑 | 1.5–1.7 | |

**边界**：这一层只管形态。"粗细差异"由错位堆叠产生，不由线宽参数产生。

---

## M3 · 流动（Flow）——每一笔"往哪走"
三层，各自独立、都可局部化。**权重最强者赢。**

| 层 | 变量 | 改什么 | 何时用 |
| --- | --- | --- | --- |
| 全局朝向 | `--flow-bias` / `--flow-from-burst` | 只定"沿线往哪头" | 兜底。整张有压倒性方向时 |
| **分区朝向** | `--flow-region X,Y,RX,RY,ANGLE[,S]` | 同上但限定椭圆内 | **默认手段**，一个元素一条 |
| 分区旋转 | `--swirl X,Y,S,R[,RATIO,TILT,PITCH]` | 改场的几何 | 只给天然同心的结构 |

### M3.a 三维漩涡
`RATIO`=投影椭圆的短长轴比，`TILT`=长轴倾角，`PITCH`=径向内收。
在**水面平面**里旋转再把速度投影回画面——透视压缩因此自动产生（端部慢、鳍部快），速度按 1/r。
**判据**：`RATIO` 必须实测（拟合泡沫环的主轴），不能拍脑袋给 1.0。

| 支撑变量 | 作用 |
| --- | --- |
| `--coherence` | 跟随多大的形（45 = 只跟大形） |
| `--flow` / `--boil` / `--trail` | 位移量 / 随机抖动 / 拖尾 |
| `--conserve` | 密度守恒，消除吸引子假轮廓。**必开 1.5** |

**验证（不可省）**：相位互相关逐区测位移，与物理对照表核对。方向靠眼睛看会错。

## M4 · 溃散（Dissolve）——可选，非每图必用
`--dissolve DEG,START,SOFT[,BREATH]` + `--escape` + `--turbulence`

- **与 M1 完全解耦**：不再强制开 mass。想要实体就显式 `--mass 1`。
- 逃逸先沿形体走、再转向逃逸方向，途中走 curl 场（散度为零 → 打旋不发散）。
- 保留区与溃散区必须是**同一种材料的不同密度**，不是两种材料。

**开关条件**：主体有"标志性形体值得保留 + 有一部分适合失去"时才用。原作者也不是每张都变。
**边界**：溃散比例上限——马 solid 69%、头像 38%。剪影辨识度靠轮廓的（马）不能多散。

## M5 · 空域层（Void）——黑场里的东西
和 M1–M4 完全无关的独立层。

### M5.a 雨点（Rain）— 当前争议最大，见提案
| 变量 | 作用 | 当前 | 实测参照 |
| --- | --- | --- | --- |
| `--rain` | 数量 | 7.0 | |
| `--rain-block` | 方块大小（输出 px） | 1.7 | 原作面积中位 10px² |
| `--rain-short` | 长度幂律偏斜 | 4.0 | 原作长度 4/4/5/7/17，中位 **5px** |
| `--rain-angle` / `--rain-spread` | 基准角 / 角度散布 | 150 / 4 | |
| `--rain-flow` / `--rain-flow-scale` | 平滑角度场幅度 / 胞尺度 | 42 / 0.30 | 每根仍是直的，角度由场给 |
| `--rain-speed` / `--rain-speed-mix` | 基准速 / 逐根倍率 | 1 / 整数表 | 原作位移 0–19px/帧，变异 0.60，与长度无关 |

### M5.b 星爆 / 星点
`--burst-at X,Y,S`、`--stars`。独立于雨。

## M6 · 输出（Output）
`--palette` / `--size` / `--seconds` / `--fps` / `--mp4` / `--seed`。
无缝循环校验：|末帧−首帧| ≈ 相邻帧差；大尺度密度相关 > 0.99。
