### 0.2 测量协议（"单帧协议"，与我们的静态 PNG 严格对齐）

我们的对照图是**单帧 PNG**，原作是 12/24 帧动画。时间平均会把逐帧 churn 的噪声抹掉，
使小尺度 CV 系统性偏低——**跨侧比较一律用"第 0 帧、单帧"协议**，时间平均结果只用于旁证。

- **密度场**：4 原生 px 胞内亮像素占比（单帧 → 每胞 17 个可能取值，两侧同样量化）。
- **主体（body）**：把密度场按 `S/8` 平滑，取该平滑场自身 99 分位的 **0.30 倍**为阈值，
  连通域保留 ≥1%·S²，**再填内部空洞**。用相对阈值+填洞是为了避免"用密度阈值定义主体，
  再去量主体内部密度"这一自证循环，也保证"空心"若存在不会被排除在外。
- **致密核（core）**：绝对阈值 0.12 填充率的连通域（≥100 胞），填洞。与 PROPOSALS_EDGE 同定义。
- **S**：√（区域面积），原生 px。所有块尺寸、距离都按 S 归一。

### 0.3 工具自检（本项目两次翻车的对策）

1. **Python 端口的位级校验**：所有测量先在页面 JS 里实现，再在容器里用 Python 重写一遍
   （`scratchpad/dplib.py`）。两边跑同一个用**相同 LCG**（含 JS 双精度乘法溢出行为）生成的
   480×480×6 帧合成图，逐项对比：globalMean 0.09565 / coreS 212.15 / bodyS 210.22 /
   CV 曲线 [2,0.454][4,0.383][8,0.333][16,0.298][32,0.257] / 深度剖面 [0.302,0.361,0.401,0.480] /
   峰显著度 [5.03,0.90,0.71] —— **两边完全相同**。因此"原作用 JS 测、我们用 Python 测"不引入方法差。
2. **敏感度**（每条结论都跑过，翻转与否逐条记在提案里）：
   - 亮度阈值 THR ∈ {32, 60, 100}（我方；原作二值，无自由度）
   - core 阈值 ∈ {0.08, 0.10, 0.12, 0.15, 0.18, 0.22}
   - body 相对阈值 f ∈ {0.20, 0.30, 0.45} × 平滑尺度 ∈ {S/6, S/8, S/12}
   - 统计块 b ∈ {2,3,4,6,8,11,16,22,32,45} 原生 px，且每个 b 用 3 个网格偏移平均
   - 峰值平滑尺度 ∈ {S/24, S/16, S/10}
   - 帧序号 ∈ {0, 5, 7}
3. **已知会骗人的量，本文不用作证据**：
   - **块面积 vs 局部密度**：密的地方笔触互相粘连成大连通域，测得的"块变大"是合并假象，
     无法据此判断作者是"改数量"还是"改笔触大小"。列为**无法定论**（§4）。
   - **单帧密度场的自相关长度**：单帧场被二项噪声支配（样本S/样本B 在 lag=2 胞就掉到 0.13/0.03），
     所测"相关长度"几乎全是噪声宽度。改用 CV-尺度曲线 + 噪声扣除代替。

## 2. 提案

### D-1 主体外的"近场晕"是缺失最严重的一层：新增 `--halo`，目标核外 0.25S 处填充 0.03–0.08
- **目标模块**：M2（dust 权重场）；与 M5.a 雨层解耦
- **证据**：致密核外 0.15–0.35 S 带的平均填充率，原作 10/10 件 ≥ 0.034（样本A .034 / 样本H .034 / 样本B .040 / 样本S .051 / Silent .055 / 样本O .066 / 样本M .068 / 样本N .069 / Axis .079 / 样本C .162），我们 horse **.0057**、vortex **.0157**（THR 32/60/100 下 .0091/.0057/.0081 与 .0201/.0157/.0101，全部低于原作最小值）。全幅"薄雾档（.02–.10）"占比原作中位 .348，我们 .104/.123。代码根因在 **L920–L929**：`floor > 0` 时 `lift = clip((g_w−floor)/(1−floor))`，**低于 floor 的像素权重恰好为 0**（边缘项也被 `(lift>0)` 关掉），而 `--floor auto` 在 **L657–L662** 取的是 `percentile(gray, 65)`——**整张图 65% 的面积被判死，dust 层在那里一粒都不落**；主体外的墨只能来自 `--rain`（**L998** `n_rain = W*H*0.00013*rain/ss²`）与 `--stars`，实测落在 0.005–0.02 档。
- **提案内容**：新增 `--halo H`（默认 **0.25**，取值 0–1）：在 L926–L929 求得 weight 之后、L941 之前，把被 floor 判死的区域按**主体的软距离场**补回一层权重：`weight += H · w_body_mean · exp(−d/(0.45·S))`，其中 d = 到主体软掩膜的距离，S 由 SUBJ 场面积开方现算。等价于"floor 不再是硬刀，而是留一条按距离衰减的尾巴"。**不改 `--floor` 的语义**（它继续负责"哪里是形体"），只把它的副作用（把画幅 65% 变成绝对真空）从 dust 层拿掉。
- **边界**：全部题材适用（10/10 件都有这层）。唯一例外方向是 样本A 型：样本A 的近场晕 .034 是全样本最低档，且到 1.0S 处掉到 .003（真空），所以人像/板型作品 `--halo` 取下限 0.10–0.15 且衰减尺度收到 0.25·S；场型（水/抽象/建筑）取 0.25–0.40。不适用于刻意"负形"构图里被保护的黑块（`--rain-keepout` 那类禁入区应同样禁入 halo）。
- **置信度**：**高**。10/10 件、零反例、三档亮度阈值不翻转、与代码路径一一对应（floor 硬切）。默认值 0.25 是从"薄雾档占比 .104 → .35"反推的一次标定，属**中**。
- **验证方法**：渲染后按本文协议测：核外 0.15–0.35 S 带填充率落在 0.03–0.08；全幅"薄雾档（0.02–0.10）"占画布 0.25–0.45；同时"微尘档（0.005–0.02）"不超过 0.20（否则是把雨调粗了而不是补了晕）。

### D-2 `--sparsity` 的常数减法是二值化的第二把刀：改成软膝
- **目标模块**：M2
- **证据**：**L941** `weight = np.maximum(weight - 0.02 * args.sparsity, 0.0)`。默认 `sparsity 1.8`（preset `flux` **L77**、`detail` **L106** 为 1.6）意味着从权重里**硬减 0.036**；而 L927 的权重主项是 `lift**gamma`（gamma 2.4，**L79**），`lift**2.4 = 0.036` 解出 **lift = 0.25**——**即 floor 之上、剩余动态范围下四分之一的区域，只要没有强边缘（`--edge` 项），权重被整块清零**。这与 L926 的 floor 硬切串联，产生实测的阶梯形状：我们的画布有 .418/.484 的真空 + .228/.193 的微尘，然后**直接跳到** .110/.080 的中调与 .140/.120 的厚实，`.02–.10` 这一档塌陷成 .104/.123；原作在这一档是 .098–.486（中位 .348）。
- **提案内容**：把 L941 换成软膝：`weight = w * (w**p / (w**p + c**p))`，`c = 0.02*sparsity`、`p = --sparsity-knee`（默认 **2.0**）。效果：`w >> c` 时不变；`w ≈ c` 时保留约一半；`w << c` 时按 `(w/c)^p` 平滑趋零而不是硬零。`--sparsity` 数值与语义不变，老命令的大尺度观感不变，只是中间档不再被切断。
- **边界**：适用全部题材。若用户明确要"剪影感"（如踏查 #11 轮廓型只勾轮廓），可用 `--sparsity-knee 8` 逼近现行硬切。
- **置信度**：**中高**。代码路径与阶梯形状的对应是明确的（两把硬刀 → 中间档塌陷），但"换软膝后薄雾档能补到 0.30"是推断，未试渲；`p=2.0` 是拍的。
- **验证方法**：同一命令下 A/B 渲染，测全幅墨阶梯：`.02–.10` 档从 ~0.11 升到 ≥0.25，同时 `≥.30` 档不上升（若上升说明是整体加密而不是补中间调）。

### D-3 密度是"板型 / 场型"二选一，不是一个连续旋钮：新增 `--density-regime`
- **目标模块**：M1 × M2 交界（这正是题目问的"`--density` 与 M1 形体的关系"）
- **证据**：10 件原作的主体区平均填充率 = .096 .107 .118 .124 .136 .153 .166 .223 .364 .552。
  分成两簇：**场型 8 件 .096–.223**（样本S/样本O/样本B/Axis/Silent/样本M/样本N/样本H；判据用全样本都有的"`≥.30` 厚实档占画布 ≤ .07"，其中有 q95 实测的 样本S/样本B 天花板只有 .210/.257）与 **板型 1 件 .552**（样本A，主体内 q95 = **1.000**，`≥.30` 档 .123，墨在核内 .881）；样本C .364 介于两者（粗颗粒特例，踏查已标注为采样网格特例）。我们的 horse .289 / vortex .360 **正落在两簇之间的空档**，且核内墨份额 .896/.866 是板型的（只有 样本A .881 相当），而主体内 q95 只有 .529/.808 —— **既没有场型的稀，也没有板型的实**。代码上，密度只有 **L945** `n_particles = W*H*0.020*args.density/(ss*ss)` 一个全局标量，M1 的形体选择（`--mass`）与它完全不通气（L933 只做压制），所以"选哪种密度状态"目前没有任何入口。
- **提案内容**：新增 `--density-regime {field,plate}`（默认 `field`）：
  - `field`：主体区目标填充率 **0.12–0.20**，主体内 q95 ≤ 0.30，`--halo` 取 0.25–0.40，`--mass 0`；
  - `plate`：主体区目标 **0.50–0.60**，允许饱和（q95 ≥ 0.9，靠 `--mass 1` 的实心网点层提供，不靠堆笔触），`--halo` 0.10–0.15，衰减尺度 0.25·S。
  实现上 regime 只做两件事：给 `--density` 一个按目标填充率反解的建议值（渲一帧、量主体区填充率、二分一次），并设 `--halo` 与 `--mass` 的默认。**不允许 regime 偷偷改别的参数**（MODULES 开篇的 `--dissolve` 教训）。
- **边界**：`plate` 只对"有实体剪影且要保留辨识度"的题材用（原作里只有人像 样本A 一件实测支撑，踏查里 #8/#15 同类但拿不到数字原图）。水/漩涡/抽象/建筑一律 `field`。样本C 型粗颗粒不进这套（它靠更大的采样网格取得密度感，是 M2 的块尺寸问题不是数量问题）。
- **置信度**：**中**。"两簇"在 n=10 上目视清楚（.223 与 .364 之间、.364 与 .552 之间都有空档），但 .223→.364 的空档只隔着一件 样本C，样本不足以称之为双峰；把它当"两个可选预设"而不是"自然规律"来落地是安全的。
- **验证方法**：渲染后测主体区平均填充率与 q95：`field` 应 0.12–0.20 / q95 ≤0.30；`plate` 应 0.50–0.60 / q95 ≥0.90。同时全幅填充率两者都应落在 0.03–0.11（原作全样本区间）。

### D-4 总墨量不用改，改的是分配：`--density` 的语义从"撒多少笔"改成"主体撒多少"
- **目标模块**：M2
- **证据**：全幅填充率——原作 .026 .028 .035 .057 .076 .083 .087 .100 .102 .112（中位 **.079**），我们 **.087 / .086**，落在原作分布的正中间。而墨在致密核内的份额原作中位 .32（9/10 件 ≤.73），我们 .896/.866。**总量对，分配错。** 代码上 L945 用一个标量决定全图笔数、L946–L947 用 `rng.choice(probs)` 一次多项抽样把它们全部按 weight 分配——weight 在 floor 以下恒为 0（L926–L929），所以"分配"这一步在数学上就不可能把墨放到主体外。
- **提案内容**：把 L945–L947 拆成两次抽样：`n_subject = W*H*0.020*density/(ss*ss)` 按现行 weight 抽；`n_halo = n_subject * --halo-share`（默认 **0.45**，即目标"墨的 31% 在主体外"）按 D-1 的 halo 权重场单独抽。两组粒子共用 M2 的笔触形态与 M3 的流场，只是出生分布不同。这样 `--density` 依旧只管主体，用户的既有直觉不变。
- **边界**：`--halo-share` 对 `plate` regime 取 0.12–0.18（样本A 实测核外墨份额 .119）；对 `field` 取 0.45–0.85（样本S .811 / 样本B .843 / 样本O .776 / Axis .706 / 样本N .517 / 样本M .384 / Silent .267）。**注意 Silent/样本M 的核外份额低是因为它们的"核"本身就占画布 33%/29%，不是因为外面空**——所以这个参数要和 D-1 的核外填充率一起验，不能单看。
- **置信度**：**中高**。全幅总量相等、核内份额差 2.7 倍，两项都是直接测量且阈值稳定；拆分实现方式（两次抽样）是最小改动的推断，属中。
- **验证方法**：渲染后测：全幅填充率 0.03–0.11；墨在 0.12-核内份额落到 0.30–0.70（field）或 0.80–0.90（plate）；且 D-1 的核外 0.25S 填充率同时达标（两者必须一起满足，只满足一个说明是把雨调多了）。

### D-5 场型作品需要 3–5 个密度焦点；我们只有 1–2 个
- **目标模块**：M2（weight 场的构造）
- **证据**：持久度 >1.5σ 的局部极大值数：样本S 4 / 样本B 4 / Axis 4 / 样本M 3 / 样本N 3 / Silent 4 / 样本C 7；单焦点的只有 样本A 1、样本O 1、样本H 2。我们 horse **1**、vortex **2**。当前 weight 直接来自源图亮度的 gamma 映射（L927/L929），焦点数完全由源图决定，没有入口。
- **提案内容**：新增 `--dens-foci N[,AMP]`（默认 **0** = 关）：在 weight 上叠加 N 个高斯凸起，中心从**源图自身**的亮度极大值里取（不是随机撒，避免凭空造结构），σ = 0.12·S，幅度 AMP（默认 0.5，相对该处 weight）。`field` regime 建议 N=4，`plate` 建议 N=1。
- **边界**：只对 `field` regime 开。人像板型不要开（样本A 实测就是单焦点，多焦点会把脸打花）。漩涡类（样本O 实测 1 个焦点）也应保持 1——**"场型 = 多焦点"并不普适，样本O 是反例**，所以 N 必须显式给，不能由 regime 隐含。
- **置信度**：**中低（标"不稳"）**。焦点计数随平滑尺度 S/24→S/10 有 ±1–3 的漂移（样本S 5/4/4，样本B 7/4/3）；分组结论（样本A/样本H/样本O 单焦点 vs 样本S/样本B/Axis/抽象件多焦点）在三个尺度下不翻转，但 样本O 与 样本B 同为"水/漩涡"却分属两组，说明题材不能决定它。
- **验证方法**：渲染后用同一持久度算法在 S/24、S/16、S/10 三个平滑尺度各测一次，>1.5σ 的峰数在三个尺度上都落进目标区间 ±1。

### D-6 不要再加"云状低频噪声"——这一项我们已经达标（负面结果）
- **目标模块**：M2（**否决一类改动**）
- **证据**：(a) CV-块尺寸双对数斜率：原作 12 个配置 −0.35…−0.51（时间平均）、单帧 −0.42…−0.81；我们 −0.43/−0.52（THR 32/100 下 −0.42…−0.56）。**同区间。** (b) 平滑到 S/16 后的整场 CV：原作 10 件 = .353 .361 .362 .374 .390 .392 .400 .404 .416 .500（中位 .391），我们 .386/.448。**同区间，我们甚至偏高。** (c) 噪声扣除后的结构性 CV（core 内）：原作 .276–.409，我们 .253–.276，**低约 25%，不是数量级**。
- **提案内容**：**不新增低频噪声乘子。** 若将来仍需微调，上限锁死：`--dens-cloud`（胞尺度 0.15–0.25·S，幅度 ≤0.25），默认 0，并在文档写明"本项实测无缺口，调它属于风格化偏离参照"。D-1/D-2/D-4 落地后应重测本项，若结构性 CV 超过 0.45 说明补过头。
- **边界**：全题材。
- **置信度**：**高**。三条互相独立的度量（斜率、平滑场 CV、噪声扣除 CV）在两侧全部重叠；body 定义 f=0.20/0.30/0.45 三档不翻转。
- **验证方法**：渲染后测 CV(b) 斜率应在 −0.35…−0.60，平滑到 S/16 的整场 CV 在 0.35–0.50。

### D-7 不要做"空心化 / 边缘加厚"——(b) 已被 10 个剖面否掉（负面结果 + 一处防呆）
- **目标模块**：M2（`--edge`）/ M1
- **证据**：见 Q2 表，10 个内部剖面全部是"贴边最稀 → 向内升高 → 持平"。唯一的向内衰减是 样本A 完好侧从 0.09S 的 0.793 掉到 0.28S 的 0.574（−28%），我们的 horse 是 0.406→0.334（−18%），**同向且量级相当**。当前实现里唯一能造出"边缘壳"的是 **L927/L929** 的 `args.edge * emag**0.7`（preset `flux` **L79** edge=0.7、`detail` **L108** edge=0.5）：它把梯度大的地方直接加权。实测我们没有过冲，说明现值安全。
- **提案内容**：**不新增任何空心化/壳层参数**。加一条防呆：把 `--edge` 的上限软限在 1.0，并在帮助文本注明"edge 只用于让轮廓可辨，超过 1.0 会产生参照里不存在的壳层"。若日后确实要复现 样本A 的"皮下略密"，用 `--core-soften`（深于 0.15S 处按 `1−0.20·(d/S−0.15)/0.15` 衰减，默认 0）——但**当前没有证据说明需要它**。
- **边界**：全题材。
- **置信度**：**高**（10/10 件、core 阈值 0.10/0.12/0.15 下形状不变、填洞保证空心不会被掩盖）。
- **验证方法**：渲染后测内部深度剖面：0.05S → 0.14S 必须单调不降；0.14S → 0.28S 的跌幅 ≤30%。

### D-8 主体占画幅比例不是差异所在（负面结果，防止把 D-3/D-4 的目标值套错场景）
- **目标模块**：M0（输入判定/构图自检），不是 M2
- **证据**：body/画幅 —— 原作 .057 .155 .162 .181 .192 .414 .472 .490 .525 .635，我们 .272/.211，**落在原作分布中段，不是异常值**。派生复合量"主体贡献的全幅墨量"（body占比 × 主体区填充率）：原作 .013 .018 .019 .044 .064 .065 .066 .081 .086 .097（中位 **.065**），我们 **.079 / .076** —— 仍在原作区间内（低于 Silent .097、略高于中位）。**这个量不区分两侧。**
- **提案内容**：**不新增参数、不加阈值告警**。记录事实：原作里 body 占比大的几件（样本O .414、Axis .525、样本N .472、Silent .635）填充率都只有 .107–.153 —— **摊得开就摊得薄**；这条"面积与浓度互补"的关系可作 D-3 选 regime 时的旁证（主体占画幅 >0.35 的构图不要选 `plate`），但不足以做成硬判据。
- **边界**：只作为 D-3 的选型旁证。
- **置信度**：**低**。n=10，复合量在两侧重叠，且构图是创作选择不是密度规律。
- **验证方法**：无独立验证；随 D-3 一起复核即可（渲染后该乘积应落在 0.01–0.10 的原作区间内）。

### 我认为的真实机制

**原作者的密度不是"主体内部按某个规律排布"，而是"整幅的墨往哪儿分"。**

三条互相独立的实测支撑：

1. **总量相同**。全幅填充率：原作 .026–.112（中位 .079），我们 .087/.086。**我们并没有画得更多。**
2. **分配相反**。墨在致密核内的份额：原作 9/10 件 ≤ .73（中位 .32），我们 .896/.866。
   核外 0.15–0.35S 带的填充率：原作 10/10 件 ≥ .034（中位 .061），我们 .006/.016 —— **零重合**。
3. **档位是二选一，中间带是空的**。主体区填充率：原作 8 件挤在 .096–.223（场型），1 件 .552（板型，
   主体内可达 1.000 的真实心），我们 .289/.360 卡在中间——**既没有场型的"稀"，也没有板型的"实"**。
   全幅墨阶梯上这表现为：原作把 10–49% 的画布放在 0.02–0.10 的**薄雾**档，我们只放 10–12%；
   原作把 0–12% 放在 ≥0.30 的**厚实**档，我们放 12–14%。

用户看到的"原作没我们这么密"和"有疏密变化"其实是同一件事的两面：
**原作把同样多的墨摊到更大的面积上，于是主体本身变淡、主体外出现一层薄雾，"张弛"就出现在主体与虚空之间的这段过渡里，而不是出现在主体内部。**
我们的主体内部起伏（CV、频谱斜率、深度剖面、焦点结构）在可测范围内**已经和原作一致**——
把力气花在"给主体内部加不均匀"上是错方向；该改的是 floor 硬切（L920–L929 + L657–L662）
与 sparsity 常数减法（L941）这两把把中间调切掉的刀，以及 L945–L947 那一次"全部按主体权重分配"的抽样。

### 作品之间的不一致（如实记录，不强行归纳）

- **#1 样本A 是 10 件里唯一的"板型"**：主体区 .552（次高的 样本C 只有 .364）、
  主体内出现 q95=1.000 的真实心、墨在核内 .881、远场 1.0S 处掉到 .003 的真空。
  **对这一件，我们不是太密，而是太稀（.289/.552 = 0.52×）。** 把"整体没这么密"当成普适结论是错的。
- **#13 样本C 的近场晕 .162 是全样本中位（.061）的 2.7 倍**，且焦点 7 个——它的密度感来自更粗的
  采样网格（原生 960×960，只 2× 放大），与其余作品不是同一套参数体系。踏查已标注为特例，本文不参与归纳。
- **#5 样本O 与 #6 样本B 同为"水/漩涡"却一个单焦点一个多焦点**，说明 (e) 不能按题材下规则。
- **#9 Silent / #10 样本M 的"墨在核内份额"高达 .733/.616**，但那是因为它们的"核"本身占画布 33%/29%
  （满屏噪点作品），不是因为核外空——它们的核外 0.25S 填充率仍有 .055/.068。
  **"核内份额"这个量必须和"核外填充率"一起读**，单看会得出相反结论。
