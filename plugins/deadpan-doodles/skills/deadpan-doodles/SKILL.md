# 沙冰 · Deadpan Doodles

总风格是“小孩子认真画出来的”：大小分配不周全，表情一本正经，笔线有自然的迟疑和补画，水色轻薄而有湿渗。以包内用户选定的 B 图为视觉基准；童趣与笨拙仍须保留这张图的克制、空气感和冷幽默。人物、动物、植物、物件与完整场景均可创作。

## 执行

1. 读 [PROTOCOL.md](PROTOCOL.md)，确定新作或局部修改。真人辨识、头像或固定人物 IP 再读 [人物模块](references/portrait.md)。
2. 读 [STYLES.md](STYLES.md) 中的共用配方及本次模式；从 [资产索引](references/style-assets.md) 确定参考角色，实际查看要传入的图。
3. 按协议整理内容请求，运行 [提示词组装器](scripts/render_prompt.py)。它只生成调用包，不调用模型、不上传图片。固定配方由脚本原样拼接，内容变量只描述本次主体、故事和形状分配。
4. 使用宿主图像工具生成；在 Codex 中遵守 imagegen skill。原样使用调用包的 prompt，按 references 顺序真实附图；保存本次调用包、输出与 [目视检查](references/qa.md)。没有图像工具则交付调用包并说明尚未生图。

## 关键边界

- 固定画法只来自 STYLES.md；不得临场缩写、换同义词、叠加第二套画风、把 QA 全文塞给模型。已选主体和构图仍由用户控制。
- 无统一 40%/50% 变形值。用主体内部“大块、密集细节、连接支撑”的关系描述失衡；不把正常造型单轴拉长，也不把大额头、三角猫或长发变成所有题材的模板。
- 眼睛自然配对；角色有生命感。植物物件不自动加脸。场景可以丰富，细节多少由故事决定。
- 标准生成必须附带经 manifest 校验的风格图。仅在用户明确要求无风格图时使用协议中的实验模式，并记录原因；不把文字模式称为同等复现。
- 用户已选的作品做局部编辑时优先保留该图，只改点名部分。不得借风格检查扩展编辑范围。
- 变更配方需要独立版本和重新测试；生图任务本身不授权修改 skill。用户明确改变风格时可以制作标明偏离项的实验配方，不声称仍是本标准版。
- 固定提示词与参考版本只能减少执行漂移，不能保证模型确定性或审美通过。新图经用户认可后才可成为风格资产。包内只保留本项目生成且获认可的参考；不收入第三方原图、截图或失败测试。
