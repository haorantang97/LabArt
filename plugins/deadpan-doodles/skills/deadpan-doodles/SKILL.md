# 沙冰 · Deadpan Doodles

让画里的东西有一点不合比例，却一本正经地存在。轻薄水彩负责空气感，几笔松动的线负责辨识，适度的比例反差负责记忆点。童趣是凭印象重新分配大小，不是婴儿化或故意画丑。

## 先确定画什么

从用户要求决定主体、动作或状态、用途和画幅。人物、动物、植物、物件都能独立成立；不默认头像、正方形、居中半身或背景全空。小场景只保留能解释关系的环境与道具，留白有疏密，不为填满画面添东西。

需要真人辨识、头像或固定人物 IP 时，再读 [人物头像模块](references/portrait.md)。普通动物、植物、物件不用读人物规则，也不需要用户提供真人照片。没有指定个体时，可直接从文字创作。用户要求沿用已选作品时，走下方局部修改流程。

## 比例：有一个地方不太对，但对得上这个主体

先找到主体最有辨识度、最能传达状态的部位或大小关系，让它承担主要的比例偏差。可以拉长、压短、放大、缩小或偏心；其他部分相对安静，仍看得出是什么、在做什么。不是逐个部位检查是否符合正常解剖，也不是把每个部位都夸张一遍。

偏差要能改变轮廓、重心或局部间距，一眼可见，但不必成为巨物。选择与主体有关的反差：懒猫稍长的身躯配短短收起的腿；警觉小狗偏大的耳朵配紧凑身体；一朵略显沉重的花配细细斜茎。它们是推理示例，不是每次重复的固定造型。植物不靠添人脸获得幽默，动物也不自动戴眼镜、穿衣或做人的表情；用户明确要拟人才这样做。

构图可以呼应这处失衡，却不能用歪着摆放一个比例正常的主体来替代造型。自然落笔误差是辅助，不是刻意高低眼、左右乱扭或均匀抖线。表情和姿态保持克制，像主体自己并不觉得有什么不对；不依赖鬼脸、卖萌腮红或惊叹号解释笑点。

程度由当前要求决定：默认明显但节制；要更怪，先加深现有关系；嫌过头，回收这一处，保留剩余童趣。用户已经选定的比例优先于重新设计，不能为了遵守本节而改坏认可的版本。

## 画法：薄水彩，不是加了纸纹的平涂

- 蓝黑或墨黑细笔快速勾形，长短线有停顿、少量接不上的线和重描；能由色块或留白补全的边界不必封死。不要靠均匀抖动或满纸乱线装手绘。
- 少量透明水彩铺出主体。浅色层透出纸白，局部叠色才加深，内部留白，某些边缘由湿变淡直至消失。深色毛发、叶片或衣服仍要能看到水色层次，不整块灌黑。
- 线条和色块各有走势，局部越界、漏色、空隙自然发生；不是每条轮廓都统一错开。
- 颜色跟随新主体，不固定棕发、肤色、黑衣或同一套调色盘。清爽纸底，轻微纸感即可；不靠厚纸纹、做旧、整体泛白或低饱和冒充通透。默认不加文字、签名和 Logo，用户要求时另行处理。

## 使用视觉资产与生图

使用宿主的图像生成/编辑能力；在 Codex 中遵守当前 imagegen skill 和工具规则。不要用 SVG、描边滤镜或代码拼图代替水彩生成。没有可用渲染器时，交付提示词并说明未生成。

从零生成前读 [风格资产与笔触索引](references/style-assets.md)，查看一张适合观察材质的样图，并实际通过工具图片引用机制传入。包内只有本项目生成的肖像，默认用于水彩材质；它们不是所有主体的造型模板。用户要求无图片参考时遵从并记录。

在提示词开头按实际输入顺序写清角色：照片或主体参考负责辨识；材质样图只负责薄色、叠色、露白和线色关系；用户选定的成图才负责沿用造型。非人物任务尤其要明确忽略样图的人脸、发型、眼镜、衣服及构图。通常一张材质图足够，不把整组资产反复塞入。照片只在任务需要时附加。

先用一句话说清本次的比例决定，再接动作和画法。可改写下面骨架，替换全部方括号；不把选项菜单原样发给模型：

> 画[主体及可见状态]。保留[辨识特征]，把[一个部位或大小关系]画得[具体的适度偏差]，让[轮廓/重心/间距]产生不动声色的反差；其他部分简省，仍能自然辨认。像凭印象画出来的一点不合理，不修回标准比例，也不夸张所有部位。用松动的细墨线和少量通透水彩：浅色透纸，局部叠深，色块里有白隙，部分湿边淡去，线与色不完全对齐。[画幅与必要环境]。轻巧、平静、有一点荒诞，不做精致萌系或厚重平涂。

用户要几版而未给数量时，先做两版独立图，改变主要比例关系或状态，不只换配色；指定数量或要一张时照办。不自动生成头像方案表或多格拼版。

## 已选作品的局部修改

以用户选定的图为编辑目标，只改点名的比例或细节。明确保留其他形状关系、笔触、透明度、配色和构图。例如「收回一点脸的纵向拉长，保留小身体、偏心下巴和原有水彩」；不要把“稍正常一点”解释为全面恢复正常比例。留存原图并另存新版本，检查实际漂移，不承诺像素级不变。

## 检查与交付

看真实成图：主体是否可认；比例反差是否可见且没有处处争抢；幽默是否来自造型或状态；水彩是否透出纸白并有局部叠色；样图身份有没有误带进新主体。普通比例加歪构图、普通插画加纹理都没有实现核心画法。

首批直接展示，保存实际提示词、输入角色与输出。独立测试保留第一次调用结果，即使失败也不偷偷重抽；用户要求继续时再迭代。结构校验和 Agent 自评不代表审美通过。新作品先作为候选，只有用户认可后才纳入风格资产；不收入原作者图片、截图或裁切。通过绝对路径展示本地图片，简短说明方案区别。
