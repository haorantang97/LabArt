# 人物头像专用模块

仅在真人辨识、头像或固定人物 IP 任务中使用。这里保留经过多轮人物测试的做法；“专用”不意味着每张都稳定通过，也不限制主 skill 只能画人。

## 外貌与比例分别处理

看照片后提取两三项辨识锚点：发型轮廓、分缝、眼镜、脸型趋势或衣着。照片负责“是谁”，不追踪真人五官坐标、正常解剖、摄影光影和背景。性别以用户说明为准，不用长发推断性别，也不添加胡须、肌肉、方下颌来证明男性身份。其他人物不自动套长发、黑衣；眼镜按用户偏好保留或省略。

默认可用头像加简省小半身，但遵从用户画幅和用途。按主 skill 选一个约 40% 的主要比例变化：脸的长宽、五官间距、头与身体或头发与脸的体量关系皆可。小半身用几笔衣服交代，不追踪照片的真实肩宽画成完整胸像；也不把身体强制缩成针尖。不同时放大头、额头和头发又缩小所有五官。

额头只是脸部空间的一部分，不是默认主角，也不是全局禁区。用户明确要高额头时可以画；否则不照搬材质样图的大额头。不要反过来规定眉眼必须居中、所有间距必须均匀。嫌某一处太大，只回收那一处，留下其余反常造型；不修成端正的常规肖像。

若用户特意选高额头方向，可单独描述“发际线到眉眼区域占可见脸长约 40%”这类占比，并说明端点；它是专用构型，不等于通用层“相对常态增加 40%”。两个百分比不能互换，也不同时叠加到同一个部位。

## 五官与气质

眼睛用两笔相近的竖线或短笔画，随头部角度自然成对，允许细微手绘错位。长短由这一版造型决定，不固定占脸长的比例；不要刻意高低眼、大小眼或一只点一只线。戴眼镜时，两眼在各自镜片内，镜框也不必机械完美。

鼻子小钩、短折或省略，嘴是小弧或轻斜短线。平静、认真发呆、隐约有点坏心眼，不用反派挑眉、油腻冷笑、巨大笑嘴或萌系高光。可有少量淡红水色，但不是必需腮红。

## 两个可改写方向

这是选择空间，不是每次必须出 A/B。结合照片替换外貌描述，引用主 skill 的材质和输入角色规则。

### 长脸，短短身体

> 保留人物的[外貌锚点]。主要变形是脸长与脸宽的关系：脸宽保持，脸长相对这个人常态简笔轮廓增加约 40%，成为一张明显不合正常比例、宽窄不均的长瓜子脸。拉长发生在脸的内部结构，不用增高头发、额头或脖子冒充长脸；五官随新脸形重新落笔，不恢复标准头像网格。小身体只是几笔衣服，不跟着放大成正常胸像。两只竖笔眼自然成对，鼻子小钩，嘴一笔偏侧小弧。像完全没发现比例不对，平静地看着前方，不修成专业肖像。

### 歪轮廓，小小五官

> 保留人物的[外貌锚点]。脸是宽窄不均的歪梯形。主要变形是五官簇的横向跨度相对脸宽压缩约 40%：脸宽保持，两眼外缘之间的距离约为常态的六成，眼鼻嘴简省地集中起来；纵向位置自由落笔，不把整组五官挤到脸底制造高额头。宽松的脸轮廓围着偏小的五官簇，下巴有自然偏心，别把脸一起缩窄抵消反差。两只短笔眼自然成对，鼻子短折线，嘴轻轻一斜。小身体几笔交代，表情一本正经；不靠同时夸张每个部位。

## 人物专用检查

外貌锚点在不在？两眼是否自然配对？角色有没有自己的比例特点，而不是精致时尚头像？头发、脸与衣服能否看见薄色和纸白？用户修改眼睛时，是否误改了脸型或头身关系？

用户认可哪一版，就以那张为后续母版，不把本模块的文字模板强加回去。保持角色一致性依赖实际参考和局部编辑，不承诺只凭同一个提示词每次得到完全一样的脸。
