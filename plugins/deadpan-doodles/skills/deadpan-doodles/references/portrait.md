# 人物头像专用模块

仅在真人辨识、头像或固定人物 IP 任务中使用。这里保留经过多轮人物测试的做法；“专用”不意味着每张都稳定通过，也不限制主 skill 只能画人。

## 外貌与造型分别处理

从照片提取两三项辨识锚点：发型轮廓、分缝、眼镜或衣着。照片负责“是谁”，不追踪真人五官坐标、正常解剖、摄影光影和背景。性别以用户说明为准，不用长发推断性别，也不添加胡须、肌肉、方下颌来证明男性身份。其他人物不自动套长发、黑衣；眼镜按用户偏好保留或省略。

有用户认可的成图时，它决定形状关系，照片只补辨识，不拿照片把成图修正常。用户说“像这张”“不如之前这张”时，把所选图同时当作造型和材质基准，不只提取画法。

## 童趣是空间分错了，不是脸长了

按主 skill 重组形状。头像加简省小半身是一种可选形式，遵从用户用途和画幅。避免正常肩宽、完整胸像托着一张被纵向拉伸的脸。脸内空白、五官簇与肩颈体量可以协同变化，不受“只改一项”的限制；选择一组可读的反差，不让所有器官各自夸张。

本项目用户重新选定的 B 图（见风格资产索引）可这样读：
- 上部脸内留出一块不合理地宽裕的空白，眼鼻嘴集中到下面；不是整个脸连五官一起均匀拉长。
- 宽窄不均的脸与偏心下巴保留几处笨拙折角，细脖子接一小块肩膀；肩膀不扩展成标准胸像去平衡头部。
- 眼睛是自然成对的短竖线，嘴只是平静的一笔斜线。幽默不靠鬼脸。
- 头发用少数松散的水色大块和游离细线，薄色、深叠与纸白并存，不逐根刻画。

这是所选方向的关系说明，不是所有人物必须高额头。其他角色可用宽脸边缘大片空白与偏心小五官、宽大头部与窄肩颈等不同分配。若用户嫌额头过头，只收回那片空白，同时保留五官集中、小肩颈、歪轮廓的关系；不要把所有部位一起恢复均匀。

没有统一的额头 40% 或 50% 要求。用户要求具体占比时，说明发际线、眉眼等端点；不将部位占比当作全局变形强度。

## 五官与气质

眼睛用两笔相近的竖线或短笔画，随头部角度自然成对，允许细微手绘错位；不刻意高低眼、大小眼或一只点一只线。戴眼镜时，两眼在各自镜片内，镜框不必机械完美。

鼻子小钩、短折或省略，嘴是小弧或轻斜短线。平静、认真发呆、隐约有点坏心眼，不用反派挑眉、油腻冷笑、巨大笑嘴或萌系高光。可有少量淡红水色，但不是必需腮红。

## 填入固定配方的内容

画法原文在 [STYLES.md 的 portrait 区块](../STYLES.md)，不再临场改写。本模块用于理解如何填内容，不作为第二套提示词追加。

用户明确沿用 B 图时，allocation 可写为：dominant 是上部脸内宽裕的空白；cluster 是下部集中的眼鼻嘴；support 是承接偏心下巴的细脖子与小肩膀。construction 可写宽窄不均的脸缘与偏心下巴；identity 只写本次人物的辨识特征。其他人物按其选定方向重新填这些内容，不默认同一张脸。

## 人物专用检查

外貌锚点在不在？两眼是否自然配对？是否仍是正常胸像加长脸？脸内空白与五官疏密、头与肩颈是否真正不均衡？头发、脸和衣服里能否看见薄色及纸白？局部修改有没有误改用户认可的其他关系？

用户认可哪一版，就以那张为后续基准，不把本模块的文字模板强加回去。保持角色一致性依赖实际参考和局部编辑，不承诺只凭同一个提示词每次得到完全一样的脸。
