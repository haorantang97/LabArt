# 成图检查

先把成图与实际传入的风格图并排看完整画面，再看局部。整体须保留参考的克制、冷幽默和通透；即使局部规则都满足，若变成另一种儿童画或成熟绘本，也不能宣布达标。

完整新作逐项记录“通过／未通过”与可指认部位；看不清按未通过。局部修改只检查本次授权部分及其他区域是否漂移，未授权部分可记“不适用”，不要扩大重画。

1. **主体内部失衡。** 缩略图可见大块、细节、连接的大小或疏密反差；能指出哪里空、哪里挤、哪里支撑偏小。仅拉长正常造型、放大道具或歪放物体不算。
2. **构造生涩。** 主体有认真却没安排周全的形状关系；有场景时关键环境也有这种特点。形状与接触仍可读，不能用断肢或脱离主体的器官充数。
3. **笔线自然。** 有少量停笔、补线或开放边界，其他笔画直接完整。机械抖动、全部重描、粗糙滤镜不算。
4. **水彩通透且外洇。** 有透纸浅层、透明叠色和白隙；能找到湿色越过清楚墨线、不规则地渐淡到纸白的局部，另有干边。单纯平移填色、轮廓内斑驳、统一光晕、模糊全图不算。

同时核对：
- 故事、角色、背景与所需细节保留，不以删减内容代替拙感。
- 有生命的主体柔软，动作有意图，眼睛自然配对。物件和植物不强加脸。
- 跨题材没有意外继承风格人物的头发、眼镜、性别、衣服，也没有把所有动物画成猫。
- 相对选定图的局部编辑没有把未点名的比例、材质或构图悄悄换掉。

未通过的图标为测试图。在用户授权迭代范围内按具体失败项用协议中的修正模式；若先前图已带偏造型，可新建画面，但仍使用固定配方和声明的参考。用户要求持续迭代时继续，不因一次调用完成就宣布达标；用户停止、工具不可用或需要新权限时报告具体阻碍。

检查记录包含 revision、实际调用包与输出路径、逐项观察及用户是否认可。结构校验、调用包一致、Agent 自评和用户审美认可分别记录。只做 skill 标准化时可先完成本地行为测试，不擅自把未做的生图回归写成通过。
