# Visual Acceptance And Known Boundaries

Judge each gate separately; do not average attractive composition over a
failed mechanism.

| Gate | Check |
| --- | --- |
| Projection | One coherent view; no exploded or displaced internals masquerading as transmission. |
| Attenuation | Plausible path-length/overlap cues; surface paint or color is not X-ray density. |
| Polarity | One attenuation ordering for background, body, bones, and hardware. |
| Visibility | Dense regions may conceal features instead of making everything equally transparent. |
| Structure | Trace topology and contact; mark unverified anatomy/engineering. |
| Modality | No optical highlights, refractive shell, surface-lit bones, painterly cutaway, or unrequested collage. |
| Action | Requested gesture/contact is visible; blur alone does not establish action. |
| Variation | Contract survives a named change; distinguish appearance from repeated reliability. |

## Observed Development Failures

- A concentric washer merged with a reel: the test did not establish whether a
  new occluder was added. An offset washer made the hole and blocked area readable.
- Scarf and keys preserved the baseline but retained thin-fabric photographic
  appearance. Shape preservation did not prove modality correctness.
- Horizontal motion editing retained the player while broadening major structures.
  This was one visual edit, not a numerical exposure-integration test.
- The hand-and-ball example suggests contact but does not resolve all digit
  topology clearly. Never treat it as a validated anatomical reference.
- An airborne cat and a pale-field cyclist developed lit-bone edges and transparent
  surface rendering. Repair improved polarity without verifying skeletons.
- A black-field drummer coordinated several contacts, but the requested strike
  target was not followed exactly and pedal topology remained unverified.
- Botanical dance, city cutaways, and an ecosystem inside a whale became mixed-media
  art. They are not positive realism references.

The work covers limited object, textile, action, and interference examples.
There is no repeated-seed benchmark, quantitative forward-physics validation,
or demonstrated general cross-subject stability. Use the workflow to evaluate
new outputs rather than assuming the examples establish those capabilities.
