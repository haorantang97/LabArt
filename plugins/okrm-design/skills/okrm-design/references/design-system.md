# 秩序系统

这份文件描述**秩序如何建立**，不是母版集合。每个维度先给原则，再给可操作的默认值，最后给按媒介的差异。

## 1. 装置（Device）

装置是项目唯一的概念，必须满足三个条件：

1. **来源于内容**：能指出它来自项目的哪一处既有物（名称、题目、工艺、流程、物件、惯例、语言、约束）。
2. **可以字面化**：能变成一个具体的版式或工艺决定，而不只是一个形容词。
3. **可以贯穿**：海报、书、网站、导视、邮件签名都能用同一个装置，只是尺度和材料不同。

常见的既有物与可能的字面化：

| 既有物 | 字面化方向 |
| --- | --- |
| 名字或题目的字面义 | 让标题成为一个句子；让标点、括号、引号成为识别元素 |
| 一道工艺（织、打孔、折、缝、铸） | 封面或界面用这道工艺本身：打孔、折痕、线缝、压印 |
| 一个流程（节目单、清单、时间表、索引） | 流程文本就是版面：时间表做海报，清单做封面，索引做导航 |
| 一种既有文件（手册、目录、档案盒、表格） | 借用该文件的形态与家具：目录编号、表格线、档案标签 |
| 一个场所（公共空间、住宅、街道） | 借用场所的秩序：网格、门牌、街道家具、楼体标牌字 |
| 一个对立（手／机、新／旧、硬／软、内／外） | 用交错与并置把对立排进阅读序列；两边各用一种材料或一种字 |
| 一种约束（预算、邮寄规格、单色印刷） | 把约束做成形态：折法、尺寸、单色、系统字体 |

装置陈述模板：`「X 是 Y，所以版面／界面做 Z。」`
好的陈述读起来像一个事实；坏的陈述读起来像一个形容（现代、纯粹、高级、有呼吸感）。

## 2. 排印

### 字体对

- 最多两个家族。主语是一个中性 grotesk；第二声部是文本衬线或等宽，承担题注、元数据、引文、双语的另一语。
- 系统字体（Helvetica、Arial、Times、Courier 级）是合法选择，尤其在经济性是装置的一部分时；把这个决定写出来。
- 装置要求时，换成**找到的字**：楼体标牌、街道门牌、打字机、手排铅字、老表格。找到的字要可追溯来源，并与项目内容相关，不是随机复古。
- 不要为了「有个性」选展示字体。个性来自尺度和家具，不来自字形花样。

### 尺度阶梯

至少跨三个量级，并且永远保留一个「大得不合理」的元素：

| 层级 | 相对正文 | 用途 |
| --- | --- | --- |
| 题注 caption | 0.8 | 元数据、图注、脚注、双语副语 |
| 正文 body | 1 | 连续阅读 |
| 导语 lead | 1.25 | 开篇、摘要 |
| 小标 subhead | 2.5 | 章节、分区 |
| 标题 display | 6–8 | 海报标题、页面标题 |
| 巨型 giant | 12+ | 页码、编号、索引字母、一个词 |

中间层级可以缺，跳变本身是表达。正文与题注之间的差别要小，正文与标题之间的差别要大。

### 排法

- 左齐不齐尾。两端对齐只用于装置要求的「表格感」或「文件感」。
- 大字字距收紧（负字距到字形几乎相触也可以），小字字距放开。
- 大写字母只用于家具（页码、编号、标签）或装置；正文不用全大写。
- 行长 45–75 字符；双语排版时两种语言各自成列，不混排在同一行。
- 标点可以是元素：逗号、句号、括号、斜线、冒号在标题尺度上有自己的位置和节奏。
- 不用斜体做强调；用尺度、位置或第二声部做强调。

### 页面家具

家具是重复出现的功能性文字：页码、编号、题注、时间戳、索引字母、章节名。原则：

- **做大做显眼**：家具可以是版面上最大的元素；一个大页码能撑起一整页。
- **至多三种**：超过三种家具，秩序变成噪音。
- **位置固定**：家具每页同位，变化的只有数值；这是读者识别系统的依据。
- **万物编号**：图、物件、章节、段落都可以编号；编号把题注系统和索引系统连起来。

## 3. 网格

- 网格从**折法或内容结构**派生：对半、四等分、双语双栏、节目单的时间列。不要从「12 栏」这种默认值开始。
- 网格通过**对齐被感知**，不画线；只有装置是「公共空间」「表格」「档案」类时，网格线才可以显形。
- 允许「看似无网格」的大字散布，但每个元素都要有一条可追溯的对齐线。
- 一个版面里有一处密集的排印重场，其余大面积留白。均匀分布等于没有层级。

## 4. 颜色

- 基础：纸白与墨黑。黑可以是深灰或印刷黑，白可以是纸张本色。
- 强调色至多一个，平涂、高饱和、工业感：荧光黄、信号红、工作蓝、安全橙。强调色只给一种功能（当前状态、装置本身、一个家具），不做背景装饰。
- 材料色（箔、霓虹、塑料、金属钝化）只在它承载装置时出现；不用数字渐变模拟材料。
- 不用渐变、不用阴影、不用透明叠加做「层次」。

## 5. 材料与生产

- 非涂布纸为默认；在关键处换纸（访谈册、索引、插页），换纸是阅读序列的一次换挡。
- 装订诚实可见：线缝、骑马钉、橡皮筋、夹子、图书馆装订。不做假工艺。
- 借用日常文件的形态：使用手册、档案盒、目录、表格、票据。这些形态自带家具和秩序。
- 生产限制变成决定：按邮寄规格定尺寸，按印张定页数，按单色印刷定色，按折法定栏数。每一条写成「限制 → 决定」。
- 数字媒介的「材料」是系统字体、浏览器默认、带宽与断点；同样写成决定。

## 6. 图像

- 照片要呼吸：满版出血，或者很小地放在大留白里；中间尺寸是最弱的。
- 不给图像加滤镜、描边、阴影或圆角。
- 题注是系统：固定位置、固定声部、带编号；题注可以离图很远，由编号连接。
- 图像之间用并置制造意义：新与旧、整体与局部、实物与图纸、两种语言。
- 排印可以成为图像：一个句子、一个编号、一张表可以是海报的全部。

## 7. 阅读序列

- 书用对页与折页思考：哪一页空、哪一页满、哪里折出、哪里换纸。
- 网页用滚动段落与断点思考：每一屏一个事件；断点是把版面对折。
- 展览用动线与编号思考：物件编号指向文本，文本指向物件；墙面文字可以直接放大印刷品的页面。
- 交错（interleave）是最有效的序列工具：A 的一段、B 的一段、A 的一段……让两组内容互相注释。
- 序列有一个重场：一次尺度跳变、一个折出、一个换纸，只有一次。

## 8. 按媒介的差异

| 媒介 | 装置通常来自 | 家具 | 经济决定 | 序列单位 |
| --- | --- | --- | --- | --- |
| 海报 | 题目、节目单、一个词 | 日期、编号、场地 | 单色或双色、标准纸张尺寸 | 一张纸的阅读顺序：巨型 → 标题 → 信息 |
| 识别 | 名字的字面义、机构的性质 | 编号、标点、题注格式 | 系统字体、可复制的规则 | 应用序列：从名片到建筑 |
| 书与目录 | 内容结构、工艺、归档方式 | 页码、图号、章节名 | 印张、折法、纸张、装订 | 对页、折页、换纸 |
| 杂志 | 阅读习惯、邮寄、折叠 | 页码、栏目名 | 每平方米成本、邮寄规格 | 对折后的四栏、跨折的图 |
| 展览 | 策展结构、动线、物件 | 物件编号、墙面题注 | 现成结构、标准板材、系统字体 | 动线、编号往返 |
| 网站 | 内容类型（档案、目录、期刊） | 索引字母、计数器、时间戳 | 系统字体、无图加载、断点 | 滚动段落、索引跳转 |
| 产品界面 | 用户要完成的序列 | 步骤编号、状态文字、计数 | 平台字体、组件库、性能 | 任务序列、状态切换 |
