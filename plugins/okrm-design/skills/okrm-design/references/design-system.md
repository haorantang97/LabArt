# 秩序系统

> 这份文件只在生成协议（genesis.md）第 6 步之后使用。形跟随路径：格式、材料与序列已经由第 3–5 步决定，
> 这里只处理落在纸面或屏幕上的秩序。

每个维度先给原则与证据，再给可操作的默认值与实测数值。实测来自对工作室公开发表的作品照片叠 0.1 归一化网格的
读数，精度约 ±1% 画幅；它们是起点，不是模板。

## 1. 装置（Device）

装置是项目唯一的概念。三个来源，对应三种装置陈述句型：

| 来源 | 证据里的例子（概括） | 字面化 |
| --- | --- | --- |
| **现成物／既有文件** | 艺博会的名字是「无题」→ 标题做成带题注标点的句子；目录「已经被归档」→ 图书馆装订＋贴纸；手与机器 → 打孔卡封面＋手缝内册；一本关于集合的书 → 一副扑克；一场展览的目录 → 一盒磁带；归档的临时物 → 马尼拉信封里的丝网纸与亚麻信封 | 整个物件做成那个现成物，连它的家具（标签、编号、条码、折痕）一起借用 |
| **既有系统** | 机构是公共空间 → 一张可被所有人占用的网格；讲座有 N 场 → 每翻一页划掉一场的清单；品牌有季度 → 同格式的《准备》丛书；档案有编号 → 编号即导航 | 系统本身就是版面；用尺度放大它的一个组件（逗号、页码、字母、网格线） |
| **对立** | 几何的 R 标志 vs 每期手绘的脸；前工业纸张 vs 高科技印刷；干燥的系统字 vs 霓虹、钝化钢、毛毡；历史 vs 当代交错 | 两边各用一种材料或一种字，并置或交错 |

装置陈述必须读起来像事实。写不出来就回到既有物清单。

## 2. 框架（Performative framework）

工作室用比喻与剧场组织项目：展览是剧场，物件是「道德表演」里的角色，编号指向剧本的页；书有「脚本」；
摄影是「创造一个可以即兴的情境」。对 Agent 的操作：

- **舞台**：媒介与格式，以及它的约束（纸张、折法、屏幕、邮寄）。
- **演员**：内容单元（44 件器皿、6 个晚上、26 个字母、256 件 T 恤）。
- **脚本**：阅读顺序与规则（交错、配对、编号往返、每页划掉一项）。

用一段话写出来。这段话代替情绪板；不要用参考图集合代替它。

## 3. 声部（字体）

### 证据

| 项目类型（概括） | 字体 | 模式 |
| --- | --- | --- |
| 工作室自身网站 | Helvetica/Arial 栈；Times 的小字号版本作第二声部；系统等宽 | 普遍语言 ＋ 一个有来源的衬线 |
| 回顾展同名书的书脊 | Helvetica 级 grotesk，一整句话 | 标题是句子 |
| 艺术家目录封面（藏红色） | Helvetica 级，角落的词 | grotesk 只做标签 |
| 时装设计师回顾目录 | 一个法国字厂的衬线家族，通本 | 一个家族 |
| 艺术家丛书书脊 | 字距放宽的罗马大写衬线 | 书脊即档案标签 |
| 研究计划的书 | Times 级衬线作书名 | 普遍语言 |
| 诗歌页 | 打字机等宽，极小 | 找到的字＝打字稿 |
| 艺术家大书 | 一个独立字厂的 grotesk ＋ Times ＋ Courier | 普遍语言做第二、第三声部 |
| 建筑评论季刊 | 自制 neo-grotesk（可换 Arial/Helvetica/Akzidenz 风格的 R 尾）；标志来自 1950 年代建筑标牌字母 | 普遍语言的「重演」＋ 历史现成物 |
| 莫斯科学院识别 | 一个独立字厂的 grotesk，双语 | 一个家族，双语 |
| 艺博会识别 | 从「通用字母」原则推出的自制几何无衬线，加新字符 | 现成物（通用字母）被重演 |
| 南极建筑展 | 一个 grotesk ＋ New Century Schoolbook | 两个声部 |
| 中东艺术奖的书 | Albertus | 找到的字（标牌字） |

### 规则

- **至多两个声部**；很多项目只用一个家族。
- 第一声部是**普遍语言**：Helvetica/Arial 级、Times 级、Courier 级，或系统字体。用它们是因为它们是「所有人的」，
  不是因为缺预算；把这个选择写进装置或经济决定。
- 第二声部是**找到的字**或**有来源的字**：建筑标牌、打字机、手排铅字、某一历史时期的字体，或为项目重演某个字体
  传统而定制的字。必须能说出来源，以及它与内容的关系。
- 自制字体的方式是**重演**：以一个普遍字体为底，加入对该类型「伟大先例」的替代字形，或从一个既有原则（通用字母）
  推导。不是为了「有个性」。
- 不要为了表现力选展示字体。表现力来自尺度两极、家具与材料。

## 4. 尺度（两极）

### 实测

| 元素 | 读数 |
| --- | --- |
| 书脊上的一句话（回顾展同名书） | 大写高 ≈ 封面高 1.5% |
| 羊皮纹封面上的标签字 | 大写高 ≈ 封面高 1.5%；标签宽 ≈ 封面宽 52%，高 ≈ 6%，上缘在封面高 18% |
| 藏红色封面角落的词 | 大写高 ≈ 封面高 1.5%；边距 ≈ 6% |
| 时装品牌海报上的字距放宽的品牌名 | 大写高 ≈ 海报高 2.5–3%；居中于 50% 高 |
| 诗歌页的打字机字 | x 高 ≈ 页高 0.6%；行距 ≈ 页高 12% |
| 季刊正文 | ≈ 页高 1.2%；每页两栏，各 ≈ 页宽 44% |
| 群青布面上的一个词 | 大写高 ≈ 封面高 10.5%；词宽 ≈ 封面宽 77%；基线在封面高 39% |
| 群青布面左上的编号 | 大写高 ≈ 封面高 8% |
| 季刊封面的 R 标志 | ≈ 封面高 35–40% |
| 邮票形封面的罗马大写 | 每字 ≈ 画幅高 12% |

### 规则

- 两极：**小**（题注、标签、书脊、正文：0.6–1.8% 的页高）与**纪念碑**（一个词、一个字母、一个编号：8–40% 的页高）。
- **避开中间**。36–96 px 的「大标题」是最弱的尺度；要放大就放大到不合理，否则留在题注尺度。
- 网页用 `vw` 定义字号（工作室网站：3.75vw / 2.55vw / 1.5vw），让版面「无尺度」。
- 字距：标签与小型大写放宽 0.1–0.3 em；纪念碑级收紧 −0.01 到 −0.02 em；正文 0 到 −0.012 em。

## 5. 对齐与位置

- **对齐跟随现成物**：标签居中（档案标签、邮票、书脊）；文件左齐（正文、目录、索引）；表格两端对齐。
- grotesk 的词常在**角落**（左上、右上、左下，边距约 6%），像仓库里的标记；一个词也可以从左上开始、
  在封面高 38–40% 处放成纪念碑。
- 纪念碑级的词不居中于页面中心；它要么靠上三分之一，要么靠边。
- 脊条、标签、白边都是对齐线。

## 6. 结构

- 细线是**图表**：分类表、排序线、图谱、统计图；一条细线就能把封面变成一份文件。
- 栏数由**折法**派生：对折 → 四栏对页；再折 → 八栏。
- 双语各自成列。
- 网格可以显形（机构是公共空间）或只靠对齐；「看似无网格却保持平衡与层级」。
- 固定项与变动项：每个项目列两张表。固定：格式、标志、家具位置、第一声部。变动：图像、颜色、第二声部的用法、
  每期的「情绪」。

## 7. 家具

页码、编号、题注、索引字母、标签、条码、ISBN、版权行、致谢缩写。

- 家具是**现成物的一部分**：借用了档案标签就连同它的编号格式一起借用；借用了邮票就连同齿孔与面值。
- 编号把题注系统和索引系统连起来：展览物件编号指向剧本页；档案编号就是导航。
- 书脊可以承载一整句话（标题是一个句子）或一列缩写（致谢成为图案）。
- 家具至多三种；位置固定，只变数值。

## 8. 颜色

- 一个平涂颜色作为**材料**：整张封面、环衬、标牌、幕布。证据里的颜色：藏红／芥黄、群青、橙红、柠檬黄、
  黑（布面）、纸白。字用墨黑或纸白压在上面。
- 不在版面内部撒强调色；需要区分时用位置、尺度或第二声部。
- 印刷默认：专色＋黑；图版「双黑」（两次黑）为主，彩色图版单独成帖分配（例：160 张图中 120 张双黑、40 张彩色）。
- 不用渐变、阴影、透明叠加。

## 9. 图像

### 实测

| 元素 | 读数 |
| --- | --- |
| 回顾展同名书封面的图版白边 | 左右 ≈ 封面宽 10%，上下 ≈ 封面高 5% |
| 时装品牌海报白边 | ≈ 海报宽 3% |
| 黑布面小书的封面小图 | ≈ 封面宽 40%，居中偏上 |
| 研究计划对页 | 左页图出血到页边，右页为 5×5 的图谱网格 |
| 诗歌对页 | 左页满版黑白照片，右页极小的打字稿 |

### 规则

- 照片要么**满版出血**，要么**带白边成图版**，要么**很小地放在大面积材料上**；中间尺寸最弱。
- 黑白为主；彩色是分配出来的例外。
- **并置**制造意义：一张人像配一张建筑；红色舞者配黑白舞者；历史器皿配当代器皿；树配诗。对页是基本单位。
- 照片要被「读」：每一页的图与下一页的图有可追踪的关系。
- 不加滤镜、描边、阴影、圆角。

## 10. 材料与生产

### 证据里的材料

布面与亚麻脊条（脊条宽 ≈ 封面宽 9–14%）、羊皮纹纸、牛皮纸盒、铜板、和纸袖套、马尼拉 DL 信封、PVC 护套、
Tyvek、高光文件夹、橡皮筋、箔、盲压、贴纸、打孔、磁带盒、扑克牌、环装、反光书匣、板书、铰链书脊、
60 克薄纸、非涂布、暴露的书芯、瑞士装、线缝、骑马钉、折页、八页手风琴插页、RGB 拉页、翻转的双封面、
三本同样的书装在一起（留一本、送两本）。

### 规则

- 材料来自装置：打孔卡是因为提花机；图书馆装订是因为归档；橡皮筋是因为它是一个「文件夹」。
- 工艺诚实可见：暴露的书脊、可见的线、可见的折痕。
- 在关键处换纸（访谈册、索引、插页）是序列里的一次换挡。
- 考虑书怎么打开；考虑纸厂的伦理；考虑成本每平方米。
- 数字媒介的「材料」是系统字体、浏览器默认、带宽、断点；同样写成决定。

## 11. 经济（拼版思维）

- 格式 ← 折法与邮寄规格（正方形对折成窄长的杂志能过信箱）；页数 ← 印张；每栏字数 ← 阅读速度与成本。
- 「每两张纸多四页」：把折作为空间，不只是作为节省。
- 封面「无尺度」：要在购物页的缩略图和海报上都成立。
- 预算小不是借口，是生成器：极简生产留出的时间花在委托与艺术指导上。
- 每条写成「限制 → 决定」。

## 12. 序列

- 对页是单位：避免年表，用「对抗性的图像组合」。
- 交错：A 的一节、B 的一节；历史／当代；图像／文本；诗作为图像流的脚手架。
- 换挡只有一次：折出、换纸、翻转格式、颜色图版。
- 节奏像 DJ：速度、预感、惊喜；读者是舞者。
- 书的结构可以是字母表（A–Z 26 章）、清单、剧本、信件集、索引。

## 13. 按媒介的差异

| 媒介 | 装置通常来自 | 家具 | 经济决定 | 序列单位 |
| --- | --- | --- | --- | --- |
| 书与目录 | 归档方式、工艺、内容单元数 | 页码、图号、书脊句、ISBN | 印张、折法、纸张、装订、双黑／彩色分配 | 对页、交错、换纸 |
| 杂志 | 阅读习惯、邮寄、折叠 | 标志（历史字母）、期号、页码 | 每平方米成本、邮寄规格、60 克纸 | 对折后的四栏、跨折的图、每期的「情绪」 |
| 海报 | 一个词、一张清单、一个现成物（邮票、通告） | 日期、编号、场地 | 单色或专色、标准纸张 | 巨型 → 标签 |
| 识别 | 名字的字面义、机构的性质 | 标点、编号、题注格式、网格 | 系统字体、可复制的规则、双语 | 从名片到建筑 |
| 展览 | 策展结构、动线、材料的日常性 | 物件编号、剧本页码 | 现成结构（栏杆护套、路缘石、毛毡）、系统字体 | 动线、编号往返、剧本 |
| 网站 | 内容类型、既有的界面语汇 | 计数器 `1 / 31`、`(Info)`、索引 | 系统字体、vw 字号、无图加载 | 滚动、索引跳转、一页 |
| 产品界面 | 用户要完成的序列 | 步骤编号、状态文字 | 平台字体、组件库 | 任务序列、状态切换 |
