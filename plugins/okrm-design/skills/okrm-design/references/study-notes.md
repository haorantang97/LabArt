# 研究笔记

说明方法从哪里来、怎样蒸馏、边界在哪里。它不进入交付。

## 证据基础

研究对象是一家 2008 年成立于伦敦的两人设计工作室。材料全部公开：

- **一手文字**：工作室自述（官网、回顾展新闻稿、出版社书目）；2010–2026 年间的访谈与对谈 12 篇
  （设计刊物、书籍出版访谈、时尚刊物、日本媒体、设计博物馆提名问答、艺术中心年度回顾）；
  其出版品牌的 41 条产品说明（含规格、材料、装订）。
- **二手评论**：设计媒体对其识别、书籍、杂志、展览图形的报道与评论约 20 篇；字体使用档案 7 条。
- **图像**：官网公开的 31 张作品照片，叠 0.1 归一化网格测量比例；工作室网站自身的 CSS（字体栈、vw 字号、字距）。

包内不含任何作品图片、版式文件、字体或标志。示例图均为用本方法制作的虚构项目。

## 0.3 的转向：从形到路径

用户在 0.2 之后指出：要学的是项目怎样从零到一被想出来，而不是最终的视觉表达；只蒸馏视觉无法达到原作者的高度。
证据支持这个判断：访谈与出版说明对三十多个项目的起点、提问、关键点、框架、物件与经济决定、方法、制作与延续
都有自述，而对版面的描述很少。0.3 因此把生成协议放到核心，把形降为第 6 步之后的参考；案例库（cases.md）
按类型与年份记录每个项目的路径，偏离算子（deviation-operators.md）从案例的「怪决定」归纳。

新增的证据：出版品牌 41 条产品说明与完整规格表、376 张商品图、267 张评论文章里的作品图、
一个时装品牌 2026 年展览的三篇报道、一本回顾展大书的两篇评论与装帧说明、研究计划三部曲的出版说明。

## 实测方法

1. 从官网下载 31 张公开作品照片，缩放到长边 2400 px，叠 0.1 归一化网格。
2. 读出文字的大写高、标签的宽高与位置、图版白边、脊条宽、纪念碑级字的高与宽，均以封面或页面的尺寸为分母。
3. 精度约 ±1% 画幅；透视与裁切会带来误差，数值只作起点。
4. 工作室网站 CSS 直接读取：Helvetica/Arial 栈、Times 小字号版本、系统等宽；字号 3.75vw / 2.55vw / 1.5vw；
   字距 −0.012em；黑白。

## 蒸馏方式

1. 只记录能在多个来源间互相印证的特征；单一来源降权。
2. 把观察写成可操作的规则与可检验的门槛，不写形容词。
3. 把印刷规则逐条翻译到界面，保留原则、替换材料。
4. 示例用虚构项目制作，并在验收门槛下自测；示例不复现任何研究来源的具体作品。

## 边界

- 这是一套可迁移的方法，不是该工作室的官方风格，与其没有任何关联或授权。
- 不在提示词、署名或宣传中使用工作室或设计师的名字。
- 不复制研究来源的版式、标志、折法、字体或照片。
- 方法的根（内容与概念、现成物、网格与游戏、经济、序列）属于现代主义排印、编辑设计与观念艺术的公共传统；
  本包的贡献是把它整理成可执行的工作流、实测起点与门槛。
