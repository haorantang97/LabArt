# 研究笔记

这份笔记说明方法从哪里来、怎样蒸馏、边界在哪里。它不进入交付。

## 证据基础

方法蒸馏自对一家 2008 年成立于伦敦的两人设计工作室的研究，材料是 2010 至 2026 年间公开发表的内容：
设计媒体对其识别、书籍、杂志、展览图形项目的报道与评论；工作室成员的访谈与讲座记录；
书籍设计奖项的评审说明；以及工作室回顾展的公开文字。没有使用任何未公开材料。

包内不含该工作室的任何作品图片、版式文件、字体或标志。示例图均为本项目用本方法制作的虚构项目。

## 观察 → 原则

| 反复出现的观察（概括） | 蒸馏出的原则 |
| --- | --- |
| 识别的核心装置来自名字的字面义、一道工艺、一个场所的性质或一份既有文件 | 结构来自内容 |
| 工作室自述「找到项目的关键点并夸张它」；评论称其「用尺度夸张系统的组件」 | 一个装置，放大到底 |
| 自述「排印是设计的骨干」；评论称其版式「看似无网格却保持平衡与层级」「戏剧性的留白」 | 排印是骨干；留白集中 |
| 页码、标点、编号、题注被做成识别元素；标题被当作一个句子来排 | 页面家具；文字是材料 |
| 自述「对生产的实际理解让我们拥抱限制并创造性地使用它」；一本杂志的格式直接来自每平方米成本、邮寄规格与折法 | 经济即形式 |
| 书籍常用交错章节并置新／旧、硬／软；版式跟随展览现场顺序；在关键处换纸；装订诚实（橡皮筋、线缝、图书馆布面） | 阅读是序列；材料诚实 |
| 展览图形中系统字体「干燥、机械」地应用，与情绪化的材料（霓虹、钝化钢、双面镜）形成对比 | 干的字，湿的料 |
| 自述「不相信艺术项目的答案总是企业识别」；设计被理解为「最广义的沟通方式」「一场对话」 | 禁止企业识别反射；装置陈述必须可说出 |
| 回顾展与同名书以「有意义的秩序」为题，取自一位设计理论家对设计的定义，并把「imposition」读回印刷术语（拼版） | 方法命名；经济与秩序同源 |
| 字体选择跨越系统 grotesk、独立字厂 grotesk、文本衬线、等宽与「找到的字」（住宅楼标牌字母），但每个项目至多两个家族 | 字体对；找到的字要有来源 |

## 蒸馏方式

1. 只记录可在多个来源之间互相印证的特征；单一来源的说法降权或不用。
2. 把观察写成**可操作的规则**与**可检验的门槛**，而不是形容词。
3. 把印刷规则逐条翻译到界面，保留原则、替换材料。
4. 示例用虚构项目制作，并在验收门槛下自测；示例不复现任何研究来源的具体作品。

## 边界

- 这是一套可迁移的方法，不是该工作室的官方风格，也与其没有任何关联或授权。
- 不要在提示词、署名或宣传中使用工作室或设计师的名字。
- 不复制研究来源的版式、标志、折法、字体或照片。
- 方法本身（从内容找装置、排印主导、经济即形式、序列阅读）属于现代主义排印与编辑设计的公共传统；本包的贡献是把它整理成可执行的工作流与门槛。
