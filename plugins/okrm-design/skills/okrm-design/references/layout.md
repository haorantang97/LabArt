# 排列：激进，但每一处都有来源

研究对象的排版常被形容为「字放满整页、看似无网格，却保持平衡与层级」「密集的文字、图像与留白混在一起」「粗白边与
不寻常的裁切」「旋转的字」「出血」「拼贴」。这些不是风格偏好，而是推导链第 3–4 步的结果在页面上的样子：现成物给出
格子，物件给出折与边，关键点给出被放大的那一件。这份文件列出证据里反复出现的排列动作，每个动作写明它什么时候成立。

用法：推导表第 7 步（结构）先写「现成物怎样分格」，再从下面选**至多两个**排列动作，各写一句「因为」。没有因为的
动作不用。一个项目内，动作在所有页面上保持一致——激进来自一致地执行一个极端，不是每页换一个花样。

## 1. 证据（概括，来自工作室官网作品照、自有出版品牌的产品图与已署名的报道）

- 对页常是**不对称**的：一页满版出血，另一页几乎全空，只有一张小图或几行字。
- 小图被**散放**在大面积白纸或色纸上，尺寸不一、不共享基线，大片空白被保留下来。
- 图像以**网格墙**出现：一页上 12–24 张小图或符号排成规则矩阵，对面是一张大图。
- 照片**像倒在桌上一样**互相叠压、略有角度，铺满整个对页（拼贴）。
- 字被**旋转**：书脊上的整句话，沿页边竖排的标题，邮票四边绕排的字。
- 一个词被**极宽地放开字距**，横跨整张图，像压在图上的一行标记。
- 纪念碑级的字母或词被**页边裁掉**一部分（左下角的大写字母，包装上被切断的词）。
- 一页上只有几行字，以**极大的行距**分布在整页高度上（诗的页面）。
- **密与空**并置：两端对齐的密集小字栏，对面是一张图或一片空白。
- 封面是一张**表格**：细线把封面分成格，词放在格的角上。
- **条与板**：一条竖向的纸条、色条或图像窄条横穿封面，把它分成两个区域。
- **成对**：两页用同一个构图、不同内容，像一组镜像。
- **框**：图版带很粗的白边，或一圈有颜色的细框，像装裱好的作品。
- **换纸即换版**：彩色纸的帖、半透明纸、光面图版纸在书里穿插，翻页就换材料。

## 2. 排列动作

每个动作：做什么 → 什么时候成立（指回上游的哪一类事实）→ 怎么做（起点值）→ 不成立的样子。

### A. 不对称对页
做什么：一页满版或满幅，对页近乎空，只放一件小东西。
成立：内容有「主体 vs 记录」「图像 vs 说明」的对立（第 2 步的对立面），或现成物本身是这样（相册、标本册）。
怎么做：满版页出血到三边；空页上的小图宽 ≤ 页宽 25%，或几行字落在页的上三分之一或下边距线上。
不成立：两页都放中等大小的东西，「平衡」了，什么也没说。

### B. 散放
做什么：小图或文字块散在大面积底上，尺寸不一，位置由内容决定（时间、距离、重要性、发现的顺序），不由网格。
成立：内容是零散的发现、样本、碎片；现成物是标本盘、桌面、地图。
怎么做：3–7 件，宽度在页宽 8–30% 之间至少有两档；每件的位置写一条规则（按年份从上到下、按距离从左到右）；
空白 ≥ 页面 60%。
不成立：随手摆，说不出规则；或摆满，空白消失。

### C. 网格墙
做什么：一页上同尺寸小单元排成矩阵（4 × 6、5 × 5、6 × 6），对面是一张大图或一段字。
成立：内容是一个系列、一套符号、一卷印样、一份清单；现成物本来是格子（印样、样卡、目录页）。
怎么做：单元间距 ≤ 单元宽 10%；矩阵贴边或占满版心；与对页的单张形成尺度两极。
不成立：卡片墙式的圆角缩略图，带阴影，带悬停。

### D. 堆叠拼贴
做什么：照片或纸片互相压住、带 2–8° 的角度，像倒在桌上，铺满整个对页并出血。
成立：内容是大量原始材料（市场、档案箱、拍摄现场）；制作情境是「铺在桌上编辑」。
怎么做：至少 15 件；角度只取几个值；保留纸边与阴影作为物件的痕迹（这是物件视图，不是装饰）；
同一本书里只出现在一种章节或一次换挡里。
不成立：每页都拼贴；用拼贴掩盖内容不足。

### E. 旋转与竖排
做什么：字旋转 90° 沿边走：书脊句、页边的标题、表格的列头、海报边上的日期。
成立：现成物上的字本来就是这样（书脊、档案盒侧面、邮票边、胶带、标签）；或格式是竖长的（竖折、窄条）。
怎么做：旋转的字在小的一极（1–2% 页高），或作为整条的纪念碑；读向一致（全书从下往上或从上往下，选一个）。
不成立：为了「动感」把标题斜放 15°。

### F. 放开字距的一行
做什么：一个名字或词，字距放到横跨整张图或整页宽，字号保持很小。
成立：名字是标记或封条（品牌、机构、项目编号）；它压在图上，像盖章。
怎么做：字号在小的一极；字距 0.5–2 em，或按「首字母对齐左边距、末字母对齐右边距」计算；放在图的垂直中线或下三分之一。
不成立：大字号加宽字距，变成中间尺度的标题。

### G. 被裁切的纪念碑
做什么：一个字母、编号或词放到 30–60% 页高，被一到两条页边切掉一部分。
成立：被放大的那件家具是关键点的字面化（期号、首字母、入藏号），且物件是「一系列」中的一件——被切掉的部分暗示它延续到页外。
怎么做：切掉 10–35%；只切外边，不切订口；字距收紧 −0.02 到 −0.04 em。
不成立：为了「大胆」把标题切掉，读不出是什么。

### H. 极大行距
做什么：几行字分布在整页高度，行距是字高的 10–20 倍。
成立：文字少且每行都要被单独读（诗、名单、时刻、问句）；现成物是逐行的（打字稿、日程、清单）。
怎么做：行数 ≤ 12；行距 = 可用高度 ÷ 行数；字在小的一极。
不成立：正文段落拉开行距显得「透气」。

### I. 密与空
做什么：一栏两端对齐的密集小字（正文 1.0–1.2% 页高，行距 1.25–1.3），对面或旁边是一张图或一片空白。
成立：内容里有大量文字（评论、访谈、条目）且预算按每平方米算；现成物是报纸、评论刊物、档案目录。
怎么做：密栏占满栏高，不留段间空行；空白不放任何东西，连页码也可以移走。
不成立：所有页都同一种中等密度。

### J. 表格即版面
做什么：细线把页面或封面分成格，词放在格的角上，格就是结构。
成立：现成物是表单、账本、登记卡、时刻表、分类表；内容有清楚的字段。
怎么做：细线 0.25–0.5 pt（屏幕 1 px）；格的尺寸来自字段数与折法；字贴格的左上角，内边距 = 字高。
不成立：表格线当装饰，格里什么也不对应。

### K. 条与板
做什么：一条窄的竖条或横条（纸、颜色、图像窄条）穿过整个封面或页面，把它分成两个不等的区域。
成立：物件真的由两部分构成（书脊条、贴上去的纸、两本合一、腰封）；或关键点是一组对立。
怎么做：条宽 = 页宽 6–14%；位置不在正中；条上可以有一行旋转的字。
不成立：装饰性色块。

### L. 成对与镜像
做什么：两页（或两张海报、两屏）用完全相同的构图，换内容。
成立：内容本来成对（新旧、男女装、两座城市、两种语言、前后）。
怎么做：所有坐标相同；只换图与字；成对出现至少三次才成立为系统。
不成立：只出现一次，看起来像重复。

### M. 框与边
做什么：图版带粗白边（≈ 页宽 8–12%）或一圈细的有色框，像装裱的作品；或无边出血。全书只用一种。
成立：图像本来是作品（画、照片原作）→ 框；图像是记录或现场 → 出血。
怎么做：白边四周相等或下边略宽；有色框颜色取自材料（布面、纸）。
不成立：同一本书里出血、白边、细框混用。

### N. 换纸即换版
做什么：书的不同部分印在不同的纸上（彩色纸、半透明纸、光面纸），版式随纸变：在彩色纸上散放小图，在光面纸上满版。
成立：内容有明确的层（文字／图版／档案／访谈）；经济允许一个帖用不同纸。
怎么做：换纸以帖为单位（16 或 8 页）；每种纸对应一种排列动作；在推导表里写出帖的顺序。
不成立：每隔几页换一种纸，读者不知道为什么。

## 2a. 纪念碑不一定是数字

看图评审里，按这套方法做的作品六个里有五个是同一个公式：一个巨大的编号或时间 + 细线表单。这是「被放大的那件家具」
规则用过了头。证据里被放大的东西跨度大得多：一个词、一个字母、一张被裁切的照片、一整块颜色、一种材料（布面、铜板）、
一条线（折痕、条带）、一个标点。

选纪念碑时先列出候选，再选：

| 候选 | 什么时候是它 |
| --- | --- |
| 编号、时间、数量 | 数字本身就是关键点（入藏号是唯一身份、UTC 把八个黎明放到一条线上） |
| 一个词或一句话 | 名字是字面义的、或标题就是论点 |
| 一张图 | 项目的主体是被看的（人、物、地方），且有照片 |
| 一块颜色或材料 | 物件本身的材质就是关键点（色纸、布面、毛毡、搪瓷） |
| 一条线或一个标点 | 结构本身是关键点（折、时间轴、潮线、逗号） |

检验：如果纪念碑是数字，写一句「为什么不是词、图或材料」。同一个 Agent 连续两个项目都用了巨大数字时，第二个必须换。

## 2b. 使用尺度下读得清

- 街头海报：除纪念碑外，至少有一级信息（日期、名字）在 3 米外可读，大写高 ≥ 海报高 2.5%。
- 网格、瓷砖、表格线不得穿过字：字所在的格子留空或线在字下断开。
- 演示板上每一格都要放满它要展示的物件；空的灰格是没做完。

## 3. 界面上的对应

| 动作 | 屏幕上的做法 |
| --- | --- |
| A 不对称对页 | 一屏满幅图，下一屏只有一行字或一张小图；滚动即翻页 |
| B 散放 | 绝对定位，位置由数据字段计算（年份 → y，距离 → x）；小屏退化为按规则排序的单列 |
| C 网格墙 | `grid` 等宽单元，间距 ≤ 1vw；无圆角、无阴影、无悬停放大 |
| E 旋转 | `writing-mode: vertical-rl` 或 `rotate(-90deg)` 做边栏标签、表头 |
| F 放开字距 | `letter-spacing` 由容器宽计算，或 `justify-content: space-between` 拆字 |
| G 被裁切的纪念碑 | `font-size` 用 vw 并让元素溢出视口，`overflow: hidden` 在容器上 |
| H 极大行距 | 每行一个元素，`justify-content: space-between` 撑满视口高度 |
| I 密与空 | 一列密集文本（`text-align: justify; hyphens: auto`）旁边一列空 |
| J 表格即版面 | 用 `table` 或 `grid` 加 1 px 线；导航就是表头 |
| K 条与板 | 固定宽度的竖向侧栏，颜色或图像，带一行竖排字 |
| L 成对 | 两个同结构组件并列，桌面并排，移动端上下 |

## 4. 检验

- 能指出每个动作在推导表里的「因为」。
- 动作至多两个，并在所有页面上一致执行。
- 尺度两极仍成立：激进的排列不引入中间尺度。
- 空白是被决定的：能说出这一片空白在保护什么。
- 拿掉一个动作，作品是否变得更「常规」？如果没有变化，那个动作是多余的。
