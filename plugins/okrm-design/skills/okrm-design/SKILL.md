# OK-RM Design · 有意义的秩序

一句话：**先有态度，再有形式。** 从内容与语境里找出一个可以被表演的框架，用普遍的视觉语言和
极度经济的生产把它做成物件，再把阅读编排成序列。这是一套工作方法，不是风格库。

> 最常见的失败：黑体＋网格＋一个强调色，但说不出它从内容的哪一处来。
> 第二常见的失败：把「大标题」当表达。证据里的字要么很小（题注、标签、书脊），要么巨大（一个词、一个
> 字母），很少停在中间。

## 适用与不适用

适用：书籍与目录、杂志与期刊、海报与节目单、艺术与文化机构识别、时尚品牌的文化传播、展览图形与导视、
网站、阅读与档案类产品界面、设计系统。
不适用：需要插画性或情绪化渲染的画面、吉祥物与角色、促销式的「热闹」视觉、要求装饰与特效的品牌。
遇到这些，说明不适用并建议其他方法。

## 八条原则

每条附来源依据（概括）与可检验的表现。细节见 [design-system.md](references/design-system.md)。

1. **内容与概念（Content and Concept）。** 设计是为内容建立框架，不是给内容加一层装饰。先直觉，后给直觉找理由；
   理由写成文字，不做情绪板（工作室自述「我们写很多」「不找完美的参考图，而是表述一个想法」）。
   可检验：交付里有一段装置陈述，不是一组形容词。
2. **找关键点并夸张（Magnified clarity）。** 「找出项目的关键点并夸张它，得到放大的清晰」；「一个系统，用尺度夸张
   它的组件」；「隐含的变成显性的」。可检验：只有一个被放大的东西，其余退成系统。
3. **表演性框架（Performative framework）。** 用比喻、剧场、脚本来组织：展览是剧场，物件是角色；书是「剧本」；
   在既有系统里跳舞（目录、lookbook、杂志、折页）。「没有约束就没有游戏。」可检验：能说出舞台、演员与脚本各是什么。
4. **现成物与普遍语言（Readymades and ubiquitous languages）。** 用历史现成物（一套建筑标牌字母、提花打孔卡、
   图书馆装订、邮票、磁带、扑克牌、档案信封、使用手册、橡皮筋）和普遍语言（系统 Helvetica、Times、Courier、
   条码、标签、页码）。「每样东西都来自别的东西，通常来自完全不同的功能。」参考是被**重演**的，不是被
   「借鉴外观」的。可检验：装置能指认一个现成物或既有系统；字体是普遍的或有来源的。
5. **经济即形式（Economy as form / imposition）。** 「一切基于最小值与约束」「每平方毫米都是地产」；
   成本、纸张、折法、邮寄规格、印刷工艺、页数、每栏字数都是生成器；封面是「无尺度」的；「impose」在印刷里是
   **拼版**——预见折、切、装与再媒介化之后的样子来安排一切。可检验：有一张「限制 → 决定」清单；格式可以被折法或
   邮寄规格解释。
6. **结构与游戏（Structure and play）。** 网格与系统给出一致的选择，内容给出流动的选择：杂志的标志不变而封面的脸每期变；
   丛书格式不变而图像每册变。「多样但系统」「没有一处设计是教条的」。可检验：能列出固定项与变动项各一张表。
7. **对立的张力（Duality）。** 把一物与它的对立物并置：手／机、干的字／湿的材料、几何标志／毛笔画的脸、历史／当代、
   硬／软、私人／公共、本地／全球、前工业纸张／高科技印刷。可检验：能指出版面或物件里的一对对立。
8. **阅读序列（Sequence of reading）。** 「DJ 需要舞者」：节奏、速度、预感、惊喜；交错的章节让两组内容互相注释；
   对页的力量；避免年表；让照片被「读」而不是被翻过。可检验：有页序或滚动草图，有一次换挡（折出、换纸、翻转）。

还有一条关于位置的原则，**机构工艺（Institutional craft）**：把自己放到离决策最近的地方；设计方法而不是形式；
「品牌并不存在，它只是『证明我们会以一致的方式一起工作』」。对 Agent 来说，这意味着先问清楚谁做决定、
内容从哪里来，再谈视觉。

## 工作流（八步，不要跳）

1. **读内容，列既有物。** 列出项目自带的一切：名字与题目的字面义、内容清单与数量、流程与仪式、工艺、物件、既有的
   文件形态（目录、手册、档案、票据）、语言（单语／双语）、约束（预算、尺寸、页数、媒介、工期、可用字体、
   邮寄与分发方式）。这一步不谈视觉。
2. **直觉 → 理由：写装置陈述。** 三种句型选一：
   - 现成物型：`「{内容的某处} 让人想到 {一个现成物／既有文件}，所以整个 {物件／界面} 做成它。」`
   - 系统型：`「{项目} 有 {N 个单元／一个流程／一种重复}，所以 {版面／界面} 就是这个系统本身，并把 {一个组件} 用尺度放大。」`
   - 对立型：`「{项目} 同时是 {A} 和 {B}，所以 {A 用某种材料或字}，{B 用它的对立物}，两者并置。」`
   写不出就回到第 1 步；「现代、简洁、高级」不是陈述。
3. **定框架。** 用一段话写出舞台（媒介与格式）、演员（内容单元）、脚本（阅读顺序与规则）。这段话代替情绪板。
4. **定秩序。** 按 design-system.md：声部（至多两个：一个普遍语言＋一个找到的字，或只用一个家族）、尺度（两极：
   小到题注，大到纪念碑，避开中间）、结构（折法或内容单元派生的网格；细线作为图表）、家具（页码、编号、题注、
   索引、标签）、颜色（一个平涂颜色作为材料，字用墨黑或纸白）、材料（现成物）。
5. **定经济。** 把每一条限制写成决定：格式 ← 折法或邮寄规格；页数 ← 印张；颜色 ← 单色或专色；字体 ← 系统字体
   或自托管；断点 ← 对折；图像 ← 双黑或四色图版的分配。按拼版思考：先想它被折、切、装、放到网页上之后的样子。
6. **排序阅读。** 画序列：对页、折页、换纸、翻转；滚动段落与断点；展览动线与编号。固定项与变动项各列一表。
   安排一次换挡。
7. **制作。** 平面类按 [recipes.md](references/recipes.md)（版式规范、HTML/CSS 骨架、图像模型提示词）；
   界面类按 [ui-translation.md](references/ui-translation.md)，先用 `scripts/tokens.py` 生成秩序表再写组件。
8. **验收。** 逐条过 [qa.md](references/qa.md)。装置、经济、序列三道主门任一不过，重做，不要修饰。

## 视觉词汇（实测起点，不是模板）

数值来自对工作室公开发表的作品照片叠 0.1 网格的测量，精度约 ±1% 画幅；细表见 design-system.md。

| 维度 | 实测与默认 | 条件 |
| --- | --- | --- |
| 声部 | Helvetica 级 grotesk 作普遍语言；Times 级衬线或 Courier 级等宽作第二声部；或只用一个家族 | 装置要求时换成找到的字（建筑标牌字母、打字机、手排铅字），并记录来源 |
| 尺度 | 两极：书脊／标签／题注字的大写高 ≈ 封面高的 1.2–1.8%，正文 ≈ 页高的 1.2%；纪念碑级一个词 ≈ 封面高的 10%、宽的 77%，一个字母可到封面高的 35–40% | 避开中间的「大标题」尺度；网页用 vw 让字无尺度 |
| 字距 | 标签与小型大写放宽 0.1–0.3 em；大字 −0.01 到 −0.02 em | 装置是邮票、档案标签时字距更宽 |
| 对齐 | 标签居中（标签位于封面高 18–24%，宽 ≈ 封面宽 52%）；grotesk 词在角落（边距 ≈ 6%）或左上；正文左齐或两端对齐成「文件感」 | 对齐跟随现成物：标签居中，文件左齐 |
| 结构 | 细线作图表、分类表、网格；栏数由折法派生（对折 → 四栏）；双语双栏 | 网格可显形（公共空间类）或只靠对齐 |
| 图像 | 封面图带白边：左右 ≈ 封面宽 10%，上下 ≈ 5%；海报白边 ≈ 3%；布面封面上的小图 ≈ 封面宽 40%；内页满版或并置 | 黑白为主（双黑印刷），彩色图版单独分配 |
| 颜色 | 一个平涂颜色作为**材料**：整张封面、环衬、标牌（藏红、群青、橙红、柠檬黄）；字用墨黑或纸白 | 不在版面里撒强调色；专色＋黑是默认印法 |
| 材料 | 布面与亚麻脊条（脊条 ≈ 封面宽 9–14%）、羊皮纹纸、牛皮纸盒、铜板、和纸、马尼拉信封、PVC、Tyvek、高光文件夹、橡皮筋、箔、盲压、贴纸、打孔、磁带、扑克 | 材料必须来自装置；工艺诚实可见 |
| 格式 | 227×320、230×310 的目录；正方形对折成窄长的杂志；A1 海报；DL 信封；盒 | 格式先于版式；由折法或邮寄决定 |

## 界面翻译（摘要，细则见 ui-translation.md）

- 「隐含变显性」：界面的按钮、链接、状态用文字和括号写出来——`(Info)`、`[Index]`、`1 / 31`——而不是图标。
- 普遍语言：系统字体栈（Helvetica/Arial ＋ Times ＋ 等宽）是正当选择，并写进经济决定；字号用 vw 让版面无尺度。
- 导航是索引或目录；列表是表格；图像是图版（满版或带白边），题注成系统。
- 颜色是一个平涂颜色的「材料」：整块背景或整屏切换，而不是按钮高亮。
- 动效是切换；序列是滚动与翻页；响应式按对折。

## 禁区

- **无理由的风格**：黑体、网格、全大写齐备，但写不出装置陈述与现成物来源。
- **中间尺度**：把表达寄托在 36–96 px 的「大标题」上。
- **装饰**：渐变、投影、圆角泡泡、纹理、作为装饰的图标、吉祥物、插画空状态。
- **情绪板**：用一组参考图代替一段话。
- **企业识别反射**：给艺术与文化项目先做 logo；「我们不相信答案总是企业识别，尤其对艺术」。
- **两个以上装置**；**均匀密度**；**复制**研究来源的版式、标志、折法、字体或照片；**署名**任何工作室或设计师。

## 渲染能力

界面类直接写 HTML/CSS 或 token；平面类优先写版式规范与 HTML/CSS 骨架（可打印、可截图）。需要图像模型时按
recipes.md，提示词里描述装置、现成物与秩序，不写任何工作室或设计师的名字。没有图像能力时交付规范并说明未渲染。
不要求安装依赖或切换外部服务，除非用户同意。

## 交付

- 作品（文件、HTML 或版式规范）；
- 装置陈述（一句）与框架段落（舞台／演员／脚本）；
- 秩序表：声部、尺度两极、结构、家具、颜色材料、物件材料，或 token 文件；
- 经济决定清单（限制 → 决定）；
- 固定项／变动项表与阅读序列草图；
- qa.md 的逐项结果。

研究笔记不进入交付，除非用户要求。
