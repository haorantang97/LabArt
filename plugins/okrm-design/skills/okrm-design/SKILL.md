# OK-RM Design · 有意义的秩序

一句话：**从内容自身的结构里找出一个装置，用排印把它放大，用经济性把它落地，再把阅读排成序列。**
这是一套方法，不是风格库。黑体＋红色＋网格而没有一个来自内容的理由，是这套方法最常见的失败。

## 适用与不适用

适用：海报、活动与机构识别、书籍与目录、杂志、展览图形与导视、网站、产品界面、设计系统。
不适用：需要插画性或情绪化渲染的画面、吉祥物与角色、「热闹」的促销视觉、要求厚重装饰的品牌。
遇到这些任务，说明不适用并建议其他方法，不要勉强套用。

## 五条法则

1. **结构来自内容（Found structure）。** 装置必须从项目自己身上找到：名字的字面意思、题目、工艺、流程、
   物件、惯例、语言、约束。不是从风格库里挑一个「概念」贴上去。
2. **一个装置，放大到底（One device, exaggerated）。** 找出关键点并夸张它。一个项目只有一个装置；
   其余一切退到背景里做系统。两个装置叠加等于没有装置。
3. **排印是骨干（Type is the backbone）。** 主语是干燥、机械、系统化的无衬线；表现力来自**尺度对比**与
   **页面家具**（页码、编号、题注、标点、时间戳），不来自花字体。文字本身是材料：标题可以是一个句子，
   一个清单可以就是海报。
4. **经济即形式（Economy as form）。** 预算、纸张、折法、邮寄规格、印刷工艺、屏幕尺寸、系统字体都是
   生成器。每一个限制都要转成一个**可见的**决定；限制没有留下痕迹，说明没有真正使用它。
5. **阅读是一个序列（Design the sequence of reading）。** 书、网页、展览都是「读的顺序」。用交错、并置、
   尺度跳变、折页与留白安排对比；让语境改变内容的读法。

一条补充的张力法则：**干的字，湿的料。** 当材料、颜色或场景本身带情绪（霓虹、金属、荧光纸、照片），
排印反而更干、更机械；两者的对比就是气质，不要让两边一起「有表情」。

## 工作流（七步，不要跳）

1. **读内容，列既有物。** 列出项目自带的一切：名称与题目的字面义、内容清单、流程、工艺、物件、惯例、
   语言（单语／双语）、约束（预算、尺寸、媒介、工期、可用字体）。不许在这一步谈视觉。
2. **找关键点，写装置陈述。** 从清单里挑一个能被**字面化**并能**贯穿所有应用**的东西，写成一句：
   `「X 是 Y，所以版面／界面做 Z。」`
   例：「这本目录会被归档，所以它做成图书馆装订的标准目录形态。」「这个项目讨论手与机器，所以封面用机器
   打孔、内册用手缝。」「这个机构是公共空间，所以识别是一张可以被所有人占用的网格。」
   写不出这句话就回到第 1 步；不要用「现代、简洁、高级」代替它。
3. **定秩序。** 按 [design-system.md](references/design-system.md) 确定：字体对（最多两个家族）、
   尺度阶梯（至少跨三个量级）、网格（可被感知的结构）、页面家具清单、颜色（纸白＋墨黑＋至多一个平涂强调色）、
   材料或 token。
4. **定经济。** 把媒介的生产限制写成决定：格式与折法、纸张与装订、系统字体与断点、加载与空状态。
   每条写成「限制 → 决定」。
5. **排序阅读。** 画序列草图：翻页或滚动顺序，哪里留白，哪里尺度跳变，哪里并置两种东西（新／旧、硬／软、
   图／文、双语）。书用对页与折页思考；网页用滚动段落与断点思考；展览用动线与编号思考。
6. **制作。** 平面类按 [recipes.md](references/recipes.md)（图像模型提示词、版式规范、HTML/CSS 骨架）；
   界面类按 [ui-translation.md](references/ui-translation.md)，先用 `scripts/tokens.py` 生成秩序表再写组件。
7. **验收。** 逐条过 [qa.md](references/qa.md) 的门槛。装置、经济、序列三道主门任一不过，重做，不要修饰。

## 默认视觉词汇（起点，不是模板）

| 维度 | 默认 | 变化的条件 |
| --- | --- | --- |
| 字体 | 一个中性 grotesk（系统 Helvetica 级或独立字厂的 grotesk）作主语；一个文本衬线或等宽作第二声部 | 装置要求时换成**找到的字**：街道标牌、住宅楼字、打字机、手排铅字 |
| 尺度 | 题注 1 ：正文 1.25 ：小标 2.5 ：标题 6–8 ：巨型 12+ | 永远保留至少一个「大得不合理」的元素 |
| 排法 | 左齐不齐尾；大字字距收紧，小字字距放开；大写字母只用于家具或装置 | 居中只在装置要求对称时 |
| 网格 | 由折法或内容结构派生（对半、四等分、双语双栏）；通过对齐被感知，不画线 | 装置是「公共空间」类时网格可以显形 |
| 家具 | 页码、编号、题注、时间、索引字母——做大、做显眼，成为识别 | 家具不能超过三种 |
| 颜色 | 纸白、墨黑；至多一个平涂强调色（荧光黄、信号红、工作蓝） | 材料色（箔、霓虹、塑料）只在它承载装置时出现 |
| 材料 | 非涂布纸；本地与日常的形态：图书馆装订、使用手册、档案盒、街道家具；在关键处换纸 | 装订和加工必须诚实可见，不做假工艺 |
| 图像 | 让照片呼吸：要么满版，要么很小；题注成系统；万物编号 | 不给图像加滤镜、描边、阴影 |
| 留白 | 戏剧性；一处密集的排印重场，其余空 | 均匀密度等于没有层级 |

## 界面翻译（摘要，细则见 ui-translation.md）

- 导航是**索引**（A–Z、编号、目录），不是图标栏；列表是**表格**，不是卡片墙。
- 元数据用题注声部（小号等宽或衬线）贴着内容；计数器、时间戳、编号做大，成为界面家具。
- 网格通过对齐被感知；响应式按「折法」思考：断点是把一张版面对折、再对折。
- 状态与反馈是干的：文字说明，而非插画空状态；动效是切换而非缓动表演。
- 系统字体是合法选择，并要把它写进经济决定里；颜色是纸白墨黑加一个强调色，强调色只给当前状态。
- 无障碍对比与可读尺寸是秩序的一部分，不是事后补丁。

## 禁区

- **风格化而无理由**：黑体、红色、网格、全大写，但说不出「X 是 Y 所以 Z」。
- **装饰**：渐变、投影、圆角泡泡、纹理、作为装饰的图标、吉祥物。
- **企业识别反射**：给艺术与文化项目先做 logo 再做系统；logo 不是必需品，句子、编号、标点都可以是识别。
- **多装置**：两个以上概念叠加。
- **均匀**：一切同尺度、同密度、同字重。
- **复制**：不复制研究来源的版式、标志、折法、字体或照片；不以其名义署名或宣传。

## 渲染能力

界面类产出直接写 HTML/CSS 或设计 token；平面类优先写版式规范与 HTML/CSS 骨架，可被打印或截图。
需要图像模型时，用 recipes.md 的提示词；不要在提示词里写任何工作室或设计师的名字，描述**装置和秩序**。
没有图像能力时，交付规范与提示词，并说明尚未渲染。不要求安装依赖或切换外部服务，除非用户同意。

## 交付

每次交付包含：

- 作品（文件、HTML 或版式规范）；
- 一句装置陈述；
- 秩序表：字体对、尺度阶梯、网格、家具清单、颜色、材料或 token 文件；
- 经济决定清单（限制 → 决定）；
- 阅读序列（页序、滚动段落或动线）；
- qa.md 的逐项结果。

内部研究笔记不进入交付，除非用户要求。
