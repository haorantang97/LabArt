# How the method was tested

[← APFEL Research-Led Identity](README.md)

Version 0.1.0 is the six-step method as first distilled. It was compared against
other distillations in blind tests on 2026-10-27. Each test used fresh agents that
could not see each other's work, the same written brief, and the same tools.

| Round | Brief | Compared with | Result |
| --- | --- | --- | --- |
| 2 | Saltmarsh House, a fictional salt museum | A process skill induced from about 85 APFEL projects | The process skill's research was closer to APFEL's; neither set's visuals reached APFEL's level |
| 3 | Anna Atkins exhibition; Shenguang Enamel brand | A revised version of that process skill | This method produced the more distinctive, ownable identities in both briefs and was chosen |
| 4 | Same two briefs | This method plus a rule that letterforms copy the object's measured shapes | The rule pushed letters toward copying surfaces (her handwriting, glaze drips); the original was kept |

The two examples on the plugin page are this method's round-3 outputs.

Limits: one run per method per brief; judged by eye by the author and the agent
that ran the tests; research was from web sources only, with no archive visits.
No marketplace installation or client activation result is claimed beyond the
package checks in [../VALIDATION.md](../VALIDATION.md).
