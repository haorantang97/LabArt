# 上下文：这个 skill 是怎么走到 0.6 的

给接手的会话一个完整的背景。细节以仓库里的文件为准：方法本身在 `plugins/okrm-design/skills/okrm-design/`，
每一版的变化在仓库根目录的 `CHANGELOG.md`，每一轮检验在 `VALIDATION.md`，交接流程在 `HANDOFF.md`。

## 目标

把伦敦设计工作室 OK-RM（2008 年创立）的工作方式蒸馏成一个可安装的 skill，用于平面设计与界面设计。
使用者明确要的是：**从零到一做一个项目的思路**——为什么选衬线还是无衬线、为什么是这个字体、前期怎么调研、
怎样一步步推导出视觉——而**最终产出仍然是视觉作品**，不是设计提案。光蒸馏最后的视觉效果，达不到原作者的高度。

## 研究基础

全部来自公开材料，读的是原文：工作室自述与回顾展新闻稿；出版品牌 41 种出版物的规格与 376 张产品图；
2010–2026 年 12 篇访谈与对谈；约 20 篇项目评论；7 条字体使用档案；官网 31 张作品照片（叠 0.1 网格测量比例）；
官网自身的 CSS；267 张已署名的报道配图；2026 年展览的报道。完整来源清单在 `README.md` 的 Study basis 一节，
案例与来源的对应在 `CASES-INDEX.md`。

没有拿到的：工作室关于自己方法的书本身；Instagram 档案（需要登录）；部分网站拒绝自动访问。
上个会话尝试探测官网背后的图库接口、以及用网页存档服务取内容，都被安全策略拦下。这两条路不要再走。

## 版本历程

| 版本 | 做了什么 | 为什么改 |
| --- | --- | --- |
| 0.1 | 五条规则，只靠搜索摘要（当时网络被封） | 使用者说「不够极致」 |
| 0.2 | 读完一手来源后重建：八条原则；尺度两极、颜色作为材料、对齐跟随现成物；实测数值；秩序表生成与检查脚本 | 0.1 的尺度、颜色、对齐规则被照片证伪 |
| 0.3 | 核心从「形」移到「路径」：九步生成文档（定位→延续）加一条「怪决定」；34 个案例；偏离算子 | 使用者指出要学的是从零到一的思路，不是最终视觉 |
| 0.4 | 链条一直推到作品：字体、尺度、结构、颜色、图像、序列每一步写「决定｜因为｜常规做法」；新增字体选择程序 | 使用者指出 0.3 变成了写提案，最终产出应是视觉 |
| 0.5 | 新增排列动作（14 种）、材质与线条、生图规则 | 使用者指出材质、线条、激进的排版没有体现 |
| 0.6 | 必读清单与 10 条核心规则写进 SKILL.md；留白是决定；生图不摆道具；尊重简报的工艺 | 第一次本地对照实验的审计 |

## 检验做过什么、学到什么

五轮盲测，四轮在云端，一轮在本地（细节在 `VALIDATION.md` 与 `AUDIT-01.md`）：

1. **第一轮（文字提案）**：0.3 的提案输给了 0.2。它借了简报里没有的现成物，用套话填满模板，数字也算不通。
   于是协议改成：现成物只从简报自身的物件里取；数字必须自洽；可选栏空着，不要填套话。
2. **第二轮（文字提案，新写手冷读）**：0.3 改后的版本，三个简报都被评审选中。
3. **第三轮（新简报，文字提案）**：又赢了三个，但暴露出一个噱头式的「怪决定」，划掉它整个方案不变。
   于是加了可分离性检验：划掉怪决定，物件必须跟着变。
4. **第四轮（看图，色块占位）**：无 skill 赢了三个，skill 赢了两个。暴露出套路：六个里有五个是「巨大的数字压在细线表单上」；
   物件视图看不出是物件。于是加了：纪念碑不一定是数字；物件视图要读得出是物件。
5. **本地对照（看图，真实生图）**：按使用者的盲排，skill 过了事先定的线；按模型评审没过。模型评审偏好完整和精致，
   使用者偏好留白和克制。同一条件跑两次的差距和组间差距一样大。skill 只被读了一半。

## 被证伪或放弃的做法

- 只从搜索摘要蒸馏规则；用「一个不合理的大元素」「强调色」「永远左齐」这类未经证实的规则。
- 让 skill 产出文字提案而不是作品。
- 从简报以外借一个现成物当主题（账本、车站时刻表），而简报里本来就有更准确的物件。
- 用套话填满模板的可选栏；物件决定没有数字或数字算不通。
- 可以被划掉的「怪决定」（姿态，不是决定）。
- 把「放大一件家具」固化成「巨大数字＋细线表单」的套路。
- 把整张记录搬上封面或开篇（密度过高）。
- 生图时让模型自带道具与氛围光（放大镜、红铅笔、胶片条、木桌、斜射阳光）。
- 用模型评审代替使用者的眼光。
- 同一条件只跑一次就下结论。

## 使用者的口味与判断（最重要的上下文）

- 要「从零到一」的思路，但最后要的是好的视觉作品，有灵魂，不只是漂亮。
- 不要「大众化」「传统」「稚嫩」；不要信息过密、规规矩矩的排版；要更大的留白、更纯粹。
- 这个工作室的辨识度在：锋利的线条感、不同材质之间的对比、不同纸张的运用、印刷的质感，以及浮雕等印刷技法。
- 这个工作室的题材主要是平面与书籍设计，可以延伸到网站与交互，但不像建筑导视、空间应用那么广。
- 零散的证据很难还原出作品的「系列感」，下一步应按项目系列重新蒸馏（见 [NEXT.md](NEXT.md)）。
- 第一次本地对照里，使用者最满意的两张是 Field Notes（杂志）的封面与开篇，以及 Market（摄影书）的封面与对页，都来自读了排版与材质参考的那一次 skill 运行。

## 边界

- 不复制研究来源的具体物件、版式、标志、折法、字体或照片。
- 提示词、署名、宣传里不出现这个工作室或其设计师的名字。
- 第三方图片、扫描件、长引文不进仓库。
- 这个包是独立研究，与该工作室没有关联，也不是其官方风格。

## 未解决的问题

- skill 太大，agent 会挑着读；0.6 的必读清单与核心规则是否够用，还没有检验。
- 材质与印刷工艺在 HTML 和生图里怎样表现得可信，而不是变成装饰或道具。
- 模型评审与使用者口味不一致：要么校准评审，要么只用使用者的盲排。
- 「系列感」还没有被写成可操作的规则。
