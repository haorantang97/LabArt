# 下一步方向：按系列蒸馏

写于 2026-10-27，云端会话结束前。接手的本地会话从这里开始。背景见 [CONTEXT.md](CONTEXT.md)，
第一次对照实验的审计见 [AUDIT-01.md](AUDIT-01.md)。

## 为什么换方向

0.1 到 0.6 的蒸馏，用的是零散的证据：访谈里的一句话、一张作品照片里的一个尺寸、一篇评论里的一个工艺。
这样能归纳出「手法」，却看不到一个项目是怎样作为一个**系列**成立的：从封面到内页、从第一期到第五期，
哪些不变，哪些在变；纸张、印刷、工艺、线条怎样在一个系列里互相配合。

使用者（本项目的设计师）在看完第一次对照实验后指出，这个工作室作品的辨识度主要来自：

- **锋利的线条感**：细而硬的线、精确的规线、图表、边框；
- **不同材质之间的对比**：光面对哑面、半透明对不透明、硬对软、粗对细；
- **纸张的运用**：一本书里换纸、不同的纸承担不同的内容层；
- **印刷的质感与技法**：浮雕（凸压、凹压、盲压）、烫印、专色、双黑、丝网、穿孔、模切、露出的装订，等等。

这些在零散的证据里只是名词清单（见 `material-and-line.md`），在 skill 的产出里几乎没有体现：第一次对照实验的作品，
被使用者评为「信息密度偏高、排得太规矩、像大众设计」，缺少「纯粹」和「留白」。

所以下一阶段的工作是：**以项目系列为单位，重新做一遍蒸馏**，重点放在材质、纸张、印刷技法和线条，
目标是让 skill 能说清楚「一个系列为什么像一个系列」，并让产出带上这种材质和工艺上的判断。

## 先做哪些系列

从官网的项目说明和出版目录里，优先选**有多个单元**、**材质与印刷信息多**的系列：

1. Goldwin 0：Enquiry #1–#5、hardware、Collective Study（研究计划、编号的探究、多种格式与印刷工艺）
2. Real Review：各期（竖折格式、固定的 R 标志与每期变化的封面）
3. 1017 ALYX 9SM：Preparation 等季度出版物
4. JW Anderson：show in a box 等季度物件
5. T.T：philosophy 与 2026 展览
6. A Meaningful Order：工作室回顾书（结构、装订、纸张序列）
7. In Other Words 的其他出版物：如 Frequencies（Oscar Murillo）等单本作品集
8. 机构识别：如 Newrope（ETH Zurich）、Strelka 的网格识别

每个系列都要回到项目本身：它为谁做、内容是什么、为什么是这种物件。不要只记形式。

## 每个系列交一份档案

放在本地工作区（研究素材不进仓库），每份按下面的结构写：

```text
系列：{名称}（年份，委托方，单元数）
是什么：{项目本身，一两句，来自来源的说法}
单元：{第 1…n 期／件，各自是什么物件}
不变的：{格式、标志、网格、字体、家具、某种线}
变化的：{封面图像、颜色、纸张、工艺、每期的主题}
纸张与材料：{每个单元的纸、颜色、克重（来源写了才写）、表面（光面／哑面／半透明／粗糙）}
印刷与工艺：{专色、双黑、四色、丝网、烫印、凸压／凹压／盲压、穿孔、模切、装订方式、容器}
材质对比：{在同一个物件里并置的两种材料，以及它们对应的内容层}
线条：{线的身份（结构、图表、框、手、物理）、粗细感、出现的位置；「锋利」具体是什么样}
排版：{排列动作、尺度两极、留白比例}
系列感从哪来：{一句话：是什么让这些单元一眼看出属于同一系列}
从项目推出来的那一步：{哪个材质或工艺决定是从内容推出来的，怎么推的}
证据：{来源链接；每条注明是「照片可见」「文字说明」还是「推断」}
```

每个系列另做一张接触印样（把这个系列的所有图并排），并截取边缘、表面、装订、压印的局部，用来看材质和工艺。
这些图只留在本地，不进仓库。

## 要产出的 skill 修订（0.7）

- `references/series.md`（新）：每个系列一节，从档案里摘出「系列感」「材质对比」「印刷与工艺」「线条」「从项目推出来的那一步」。
  只写描述与原理，不写可以照抄的版式、标志或字体。
- `references/print-techniques.md`（新）：印刷与工艺词表。每种工艺写：它是什么、在证据里怎么用、什么样的内容会推出它、
  怎样写进推导表、在 HTML 与生图里怎样表现、常见的误用。至少覆盖：纸张序列、凸压／凹压／盲压、烫印、专色与双黑、
  丝网、穿孔与模切、各种装订（锁线、瑞士装、裸脊、骑马钉、和式线装、活页）、容器（盒、袖套、文件夹）。
- `material-and-line.md`：把「锋利的线条感」和「材质对比」写成可操作的规则，用系列档案里的例子替换现在的名词清单。
- `SKILL.md` 的核心规则与 `qa.md`：加上材质和工艺的门槛，比如每个物件至少有一组材质对比，或者一个由内容推出的印刷工艺，
  并能在推导表里写出「因为」。
- 示例：用新规则重做一个虚构项目的封面与对页，生图只用来表现纸、压印、装订的真实质感，字仍在 HTML 里排。

## 怎么检验

- 先自查：拿系列档案对照新的 references，看能不能从 skill 的文字里重建出每个系列的「系列感」，而不是只看到一串名词。
- 再做一次对照实验，用 `docs/okrm-design/handoff-tools/`（已修好上次的问题）：
  - 简报限定在这个工作室真正的领域：书与目录、出版物、海报系列、识别的印刷部分、它们向网站的延伸。不要用建筑导视、
    工地围挡这类空间场景。
  - 对照组：0.6.0 对 0.7（新），或者无 skill 对 0.7；每组至少三次运行（第一次实验里，同一条件跑两次的差距和组间差距一样大）。
  - 文件夹用中性名字（不要带 okrm）；评审的输出文件叫 `verdict.md`。
  - **以使用者的盲排为主要依据**。模型评审偏好完整和精致，和使用者的口味系统性不一致；要用的话，把使用者的口味写进评审的第二套标准，两套都报告。
  - 使用者看重：留白、纯粹、克制、锋利的线、材质和工艺的质感；不喜欢：信息过密、规矩的大众化排版、摆拍道具。

## 边界（一直有效）

- 不复制研究来源的具体物件、版式、标志、折法、字体或照片；skill 里只写原理和从内容推导的方法。
- 生成提示词、署名和宣传里不出现这个工作室或其设计师的名字。
- 第三方图片、扫描件和长段引文不进仓库；研究素材留在本地工作区。

  `python3 -B scripts/check_packages.py` 和 `python3 -B -m unittest discover -s tests/okrm-design`。
