# Task: judge graphic design blind, from images

You are an independent, demanding art director. Work only inside this folder; do not read anything outside it and do not search the web.

`briefs.md` holds six design briefs. For each brief, `boards/board-b{n}.png` shows several anonymous directions, one per row, each labelled with a letter (P, Q, R, S …); each row shows the two images the brief asked for. Full-size images are in `images/` as `b{n}-{letter}-{i}.png`. You do not know who or what made any row, and the letters are shuffled independently for every brief — the same letter in two briefs is not the same author. Do not guess authorship.

Some rows may use generated photographs and some drawn placeholders. Judge composition, typography, line, material, colour, and how the design answers its brief; do not reward or punish a row for having better or worse photographs as such.

Write your verdict to `verdict.md`, in English. (Do not name it `judge.md`: on a case-insensitive file system that overwrites this file.) For each brief:

1. **Direction.** Which row follows most visibly from the brief's own material (its objects, numbers, places, people)? Point at what in the image shows it. Is there one rule that every element obeys?
2. **Layout.** Which row's arrangement is the most committed and distinctive, and is it coherent across its two images or arbitrary? Name the moves you see (full bleed against empty page, scatter, grid wall, collage, rotation, cropped giant type, dense text against white, table as layout, strips, pairs, frames).
3. **Type.** Which row's typeface choice and scale best fit what the brief is? Name what you see (serif, sans, mono; sizes; tracking; rotation; CJK and Latin together).
4. **Material and line.** Which row treats material (paper, board, binding, print process, surfaces, objects in space) and line (rules, tables, diagrams, frames, hand-drawn, folds) as decisions rather than decoration? Do its object views read as real objects?
5. **The safe one.** Which row looks most like what a competent agency would produce?
6. **Commission.** Which row would you commission, and what would you change?
7. **Errors.** Overflow, clipped or broken text, illegible sizes, inconsistent systems, numbers that don't add up, dates that don't match weekdays.

Then rank all rows for that brief, best first.

**Overall:**
- A table of your rankings.
- Could any row be mistaken for a specific published project, or does any row look strongly like the house style of a specific, nameable design studio? Name it if so and say which row and why; otherwise say no.
- In three to five sentences: what distinguishes the strongest work across the six briefs, and what most often weakens the rest.

Be blunt and specific. Do not score numerically.
